**道理我都知道，但我就是做不到怎么办？**

**30 个问题，帮你拆清楚：你是真的不知道怎么选，还是还没准备好承担答案**

这套问题不是帮你「狠下心」。

而是依次拆开：

**事实 → 判断 → 情绪 → 留恋 → 不可解决 → 代价 → 行动。**

**第一组｜你真的「不知道怎么办」吗？**

先检查一个最重要的问题：

**你没有答案，还是不喜欢自己的答案？**

**01** 如果现在必须在 10 秒内做决定，不允许解释，我会选什么？

**02** 如果完全没有人知道我的选择，我会怎么选？

**03** 如果不考虑「舍不得、害怕、丢脸、不甘心」，我认为更合理的选择是什么？

**04** 我已经反复想过多少次这个问题？每一次最后其实得出了什么结论？

**05** 我现在继续思考，是因为真的还有重要信息不知道，还是希望再想一会儿能得到一个自己更喜欢的答案？

这一组结束以后先填一句：

  -----------------------------------------------------------------------
  **其实，我目前的判断是：\_\_\_\_\_\_\_\_。**

  -----------------------------------------------------------------------

**第二组｜你说「我知道这不应该/是错的」，你到底知道什么？**

开始审查自己的判断。

**06** 我认为这件事「不对/不好」，具体不对/不好在哪里？

**07** 它违反的是事实、利益、价值观、底线，还是我的期待？

**08** 这是我自己的判断，还是「别人都说我应该这样」？

**09** 如果没有朋友、父母、社会、互联网告诉我什么是正确答案，我还会做出相同判断吗？

**10** 有什么新的事实出现，会让我改变现在的判断？

最后这个特别重要。

如果答案是：

  -----------------------------------------------------------------------
  **「基本没有。」**

  -----------------------------------------------------------------------

那可能说明你已经不是在搜集信息，**你已经判断完了。**

**第三组｜那你到底放不下什么？**

不要再说：「我就是放不下」。把它拆开。

**11** 如果失去这件事/这个人，我具体会失去什么？

**12** 我舍不得的是现在真实存在的东西，还是曾经拥有过的东西？

**13** 我留恋的是现实，还是「如果一切顺利，本来可以变成的样子」？

**14** 如果过去的投入全部清零，我今天第一次遇见它，还会做同样的选择吗？

**15** 我最不甘心的到底是什么：失去、失败、没有得到回报、被别人证明我错了，还是承认过去的投入已经无法收回？

这组其实是在拆：

**爱 / 依赖 / 熟悉 / 沉没成本 / 不甘 / 幻想 / 身份认同。**

它们都可以表现成一句：

  -----------------------------------------------------------------------
  **「我放不下。」**

  -----------------------------------------------------------------------

但解决方式完全不同。

**第四组｜你是不是在解决一个根本无法解决的问题？**

**16** 我现在真正想「解决」的到底是什么？

**17** 这件事真的存在一个由我控制的解决方案吗？

**18** 我是不是在等待另一个人改变、过去被改写、风险彻底消失，或者一个已经发生的结果变得没有代价？

**19** 我有没有偷偷期待一个方案：既保留现在拥有的一切，又得到新的生活？

**20** 如果这个问题未来永远不会得到一个让我满意的解释，我还能不能继续生活？

然后把事情分进两个框：

**可以解决的**

→ 行动。

**无法改变的**

→ 接受。

因为**有些问题一直解决不了，不是你不够聪明，而是它从来就不是一个等待解决的问题，而**是一个等待被接受的事实。

**第五组｜你不是不会选，你是不是哪个代价都不想付？**

这是整套里面我最喜欢的一组。

**21** 选择 A，我必须失去什么？

**22** 选择 B，我必须失去什么？

**23** 我一直拖着不选，需要持续支付什么代价？

这一问特别重要。

因为：

  -----------------------------------------------------------------------
  **不做决定也是一个决定，而且它每天都在收费。**

  -----------------------------------------------------------------------

**24** 三种代价里------A 的代价、B 的代价、拖延的代价------哪一个我最愿意承担？

**25** 我是不是一直在寻找一个根本不存在的 C：既不用失去 A，又能拥有 B，还不用承担风险？

到这里，问题已经从：

  -----------------------------------------------------------------------
  **「哪个选择最好？」**

  -----------------------------------------------------------------------

变成：

  -----------------------------------------------------------------------
  **「哪一种代价，我愿意负责？」**

  -----------------------------------------------------------------------

这才是真正的决策。

**第六组｜如果不要求自己先「放下」，你会怎么做？**

最后把情绪和行动拆开。

**26** 我是不是默认：只有不难过、不害怕、不舍得了，我才能行动？

**27** 如果允许自己继续舍不得，我还会做同样的决定吗？

**28** 如果允许自己以后偶尔后悔，我现在会怎么选？

**29** 我现在能做的最小、可逆、成本最低的一步是什么？

注意，不一定是：

  -----------------------------------------------------------------------
  分手 / 辞职 / All in / 永久离开。

  -----------------------------------------------------------------------

可能只是：

  -----------------------------------------------------------------------
  停止联系一个月。\
  投 10 份简历。\
  拒绝下一次合作。\
  停止继续投入。\
  把猫隔离到楼下。\
  做一个 30 天实验。

  -----------------------------------------------------------------------

**30** 如果一年后的我回来看今天，我希望自己至少做过什么？

然后最后重新回答第一页的问题：

+-----------------------------------------------------------------------+
| **现在，我准备怎么做？**                                              |
|                                                                       |
| **我为什么这样选？**                                                  |
|                                                                       |
| **我知道这个选择会让我失去什么吗？**                                  |
|                                                                       |
| **我愿意承担吗？**                                                    |
+-----------------------------------------------------------------------+

**「最终判断页」**

做完以后，不要只停在感悟。请填写以下表格。

**我的当前判断**

**我真正的问题不是：**

**而是：**

**我已经知道的事实：**

**我目前的判断：**

**我真正放不下的是：**

**我一直试图解决、但其实无法控制的是：**

**如果继续不做决定，我付出的代价是：**

**我愿意承担的代价是：**

**所以我接下来的最小行动是：**

**什么新的事实出现，我会重新评估这个决定：**

最后一句：

  -----------------------------------------------------------------------
  **我允许自己依然 \_\_\_\_\_\_，但我决定 \_\_\_\_\_\_。**

  -----------------------------------------------------------------------

比如：

+-----------------------------------------------------------------------+
| **我允许自己依然舍不得，但我决定不再回去。**                          |
|                                                                       |
| **我允许自己害怕失败，但我决定开始投递新的工作。**                    |
|                                                                       |
| **我允许自己不知道 AI 能不能成功，但我决定先用 90 天验证。**          |
+-----------------------------------------------------------------------+
