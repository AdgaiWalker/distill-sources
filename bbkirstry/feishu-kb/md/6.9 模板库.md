**6.9 模板库**

模板很有用，尤其当一个人还不知道从哪里开始时。它能减少空白页压力，也能提醒内容不要漏掉关键任务。

但模板最大的危险，是让"结构完整"伪装成"判断已经发生"。

**什么时候适合用模板？**

已经有明确问题、核心判断和证据，只是不知道怎样安排顺序时，模板可以当脚手架。

只有一堆材料、情绪或模糊主题时，套模板只会生产一篇看起来完整的空内容。

**四种最基本的推理路径**

**诊断型：**表面现象 → 问题重定义 → 链路断点 → 关键变量 → 下一步检查。

**观点型：**常见理解 → 解释不通的地方 → 新判断 → 判断依据 → 适用边界。

**方法型：**具体目标 → 现实限制 → 执行动作 → 常见失败 → 最小验证。

**复盘型：**原目标 → 实际结果 → 中间差异 → 错误假设 → 下一轮实验。

**模板应该在最后消失**

写完初稿以后，检查每一段是否真的推动了理解。不需要的格子删掉，重复的格子合并，让内容重新按照真实推理自然生长。

  ------------------------------------------------------------------------------------------------------
  **模板是思考的脚手架，不是成品的外墙。用户不应该看见你填了哪些格子，只应该看见判断怎样一步步成立。**
