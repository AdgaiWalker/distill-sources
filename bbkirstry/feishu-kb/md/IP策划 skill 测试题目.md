**实验命题：一个总觉得自己落后于时代的年轻人**

**① 先理解这个人，而不是急着创造角色**

我觉得「害怕落后」只是表面情绪。

我们先想象一个具体的人。

他可能二十多岁，刚进入职场几年。每天打开手机，都有人告诉他：

AI 又更新了，某个行业又被颠覆了，同龄人已经赚到第一桶金了，别人又掌握了新的技能。

他不是完全不想进步。

相反，他可能对世界很好奇，也愿意学习新东西。

**但他逐渐分不清：我是真的想要这些东西，还是因为所有人都在向前跑，所以我不敢停下来？**

这里存在两种不同的需求。

一种是成长的需要。他希望拥有能力、机会和选择权。

另一种是自主的需要。他不希望自己的生活永远被外界的速度决定。

这两种需要并不矛盾。

**他想向前走，但不想被推着走。**

我觉得这比「拒绝内卷」「慢一点也没关系」更值得继续挖。

因为后两者已经是非常常见的表达，而且容易把角色做成一个只会躺平、睡觉、逃避现实的形象。

但这个年轻人并不想逃避。

**② 再把他放回社会环境**

我认为这个人的矛盾，不完全来自个人焦虑。

他所处的环境正在不断制造一种评价标准：

速度快意味着优秀，效率高意味着有竞争力，持续进步意味着没有被淘汰。

尤其是在信息高度流通的互联网环境里，他每天看到的都是别人已经取得的结果，却很少看到别人真实的起点、资源和代价。

于是，他可能把别人的进度误认为自己应该遵守的时间表。

这里我想提出一个更深的判断：

**他真正害怕的，也许不是落后，而是失去按照自己的意愿决定人生节奏的权利。**

但这只是我们的候选洞察，还需要判断它是否符合目标人群。

**③ 我们想呈现一种什么样的可能性？**

我不想让这个 IP 告诉大家：

「你不需要努力。」

也不想告诉大家：

「只要坚持自己的节奏，就一定会成功。」

这两种表达都太轻易了。

我更想呈现一个生命状态：

**它知道世界一直在变化，也愿意探索世界，但它不会因为别人跑得快，就忘记自己原本想去哪里。**

它可能有时焦虑，有时着急，有时也会羡慕别人。

但它仍然拥有一种能力：在混乱中重新辨认自己的方向。

我暂时把母题定为：

**「在不断加速的世界里，重新获得决定自己方向的能力。」**

注意，这还不是角色 Slogan，而是我们内部的创意原点。

**④ 现在开始寻找叙事，而不是寻找吉祥物**

我想先探索三种完全不同的生命处境。

**方向 A：一种具有迁徙本能的生命。**

它生活在一个需要跟随季节迁徙的群体中。

所有同伴都在向同一个方向前进，但它逐渐发现，自己并不确定那个方向是否适合自己。

这个方向的叙事优势是：迁徙本身就具有时间、方向、群体与生存的关系。

但风险是容易写成「离群者才是真正自由的」，把群体行为简单塑造成错误。

**方向 B：一种生长速度与周围不同的生命。**

它可能生长得很慢，但它并不是停止生长。

它与周围生命的时间尺度不同。

这个方向可以讨论：为什么我们习惯用同一种时间表评价不同的生命？

但风险是容易落入「慢慢来比较快」的鸡汤表达。

**方向 C：一种生活在不断变化环境中的生命。**

它的生存方式不是永远保持最快速度，而是根据环境变化调整行动。

它需要观察、判断、等待，也需要在合适的时候迅速行动。

这个方向的优势是能够同时保留主动性与自主性。

但风险是如果没有足够独特的现实原型，最后可能只会得到一个抽象的「聪明小动物」。

它害怕掉队，偶尔迷茫，会羡慕别人，也会因为自己的笨拙而沮丧。

但它不是一个等待被拯救的可怜角色。

它有自己的好奇心、脾气、愿望和行动。

用户看见它时，可能会想：「哈哈哈，这不就是我吗？」

**第二阶段：陪伴成长------建立情感连接。**

随着内容持续输出，用户逐渐了解它的不同侧面。

它会遇到新的问题，作出选择，有时成功，有时失败。

它的成长不是变成一只完美的候鸟，而是逐渐学会理解自己的处境、识别自己的需求，以及决定如何行动。

**角色不是在替用户解决所有问题，而是在展示一个生命如何尝试解决问题。**

**第三阶段：看见可能------提供认知与行动上的启发。**

这才是你真正希望产生的影响。

用户最初在它身上看见自己，后来却通过它的经历，看见了自己尚未想到的选择。

比如它曾经因为害怕掉队而拼命跟随，后来开始思考：我究竟为什么要去那里？

它不一定因此停止迁徙，但可能学会根据自己的体力调整节奏，或者在迷路时主动寻找帮助。

用户从这些故事里获得的，不只是「我被理解了」，还有：

**「原来面对这种困境，我还可以这样做。」**

这才是你说的，为痛苦和困惑提供一些解法。

**我发现这其实是一个完整的 IP 内容经营机制**

**代入 → 认同 → 陪伴 → 认知拓展 → 主体性成长。**

而且它不需要通过说教完成。

你可以通过角色的行为、选择、失败和变化，让用户自己理解其中的意义。

比如我们这只候鸟：

它某次因为掉队而非常焦虑，拼命追赶，最后筋疲力尽。

下一次遇到类似情况，它可能开始尝试观察风向、寻找适合自己的飞行方式。

它不一定立刻成功，但它开始意识到：自己并不是只能拼命追赶。

**这里真正发生变化的，不是它飞得更快了，而是它开始拥有对自身处境的判断和选择。**

这也呼应了你最初说的「通过呈现状态，彰显一种更美好的可能性」。

**我想修正我们方法论里一个重要的地方**

之前我们把 IP 的情绪价值主要理解为「被看见、被接纳」。

但现在看来，它们只是建立连接的起点。

**你的完整价值主张更接近：**

让用户通过角色看见自己，再通过角色的成长，发现新的自我理解和行动可能。

这是一种从**情绪认同走向主体性发展的叙事机制**。

而且它可以跨 IP 类型复用。

对于个人 IP，用户先因为共同经历产生认同，再通过创作者的思考与实践获得启发。

对于虚拟角色，用户先通过人格与故事产生代入，再通过持续内容看见不同的生活方式。

对于潮玩 IP，产品和形象则可以成为这种关系的具体载体。

我觉得现在可以正式确定候鸟 IP 的核心方向了：

**它不是一只需要被拯救的鸟，也不是一只最终成为飞行冠军的鸟。**

它是一只会迷茫、会犯错，但始终在学习如何理解自己、面对世界、作出选择的候鸟。

它的成长不以世俗成功为终点，而以逐渐拥有自己的判断与行动能力为方向。

**用户通过它，看见自己的现在，也看见自己可能拥有的未来。**

而且这次我们还发现了一个非常重要的策划原则：

**IP 的初始人格决定用户为什么愿意靠近它，持续的角色成长决定用户为什么愿意一直关注它。**

我认为接下来可以把这个原则落实到候鸟的具体角色设定和内容成长线里，再开始命名与视觉开发。
