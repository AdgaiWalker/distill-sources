**1. 手册定位 / 怎么用**

**定位**：通用的「创意视频收集 + 画面拆解」记录手册。收录值得参考的 Reel / 短视频，按统一字段拆结构、节奏、字幕与关键画面，方便以后任意 agent 读取学习、沿用到合适片子。\
**给谁**：要做竖屏/横屏创意短视频、日常 vlog、钩子/教程片、片头字效的 agent 或同事。\
**不给谁**：要「复刻某条原片画面 / BGM / 人脸道具」的需求------本库禁止。

**画面拆解规范 / 怎么读这份手册**

每条详卡按同一模板写；关键帧用**横向 contact sheet（一行多帧，必要时 2--3 行网格）**，图下再用时间码 + 短句标各帧。不要竖着插一长串单帧。

**原链**：可点开的原视频链接（Ins / 其他平台均可）

**时长 / 规格**：秒数 · 画幅（竖/横/方）· 有无本地样片

**钩子**：前几秒靠什么留人（画面 / 字 / 动作 / 提问）

**结构**：带时间码的段落表，如 A 0--1s：...；用来理解节奏，不是分镜照抄

**剪辑手法**：可迁移的节奏 / 转场 / 字幕 / 机位 / 调色关键词

**画面逐镜**：一张（或少量）横拼图 + 图下「01 · 0.0s · 含义」列表；拼图格内只标序号

**可借鉴点**：只学结构、节奏、字幕、转场；明确「不要照搬」什么

**未核实**：播放量、曲名、器材等标了就不能当事实写进对外文案

**给 agent 读时**：先看总表定编号 → 详卡优先读「钩子 / 结构 / 可借鉴点」→ 对照横拼图对齐视觉语言。有本地样片再开 mp4 核对；没有样片的条目只留链接，拆解深度以已写字段为准。

**Agent 调用规则（硬约束）**

**只学结构、节奏、字幕、转场**；不复刻原片画面、构图里的具体道具/人脸，也不搬原片 BGM。

**优先读「可借鉴点」**；结构表用来理解节奏，关键帧用来对齐视觉，都不是分镜照抄。

**按手法分流**（不是按某个项目）：日常 vlog 画面 → #003 / #004 / #005 / #006 / #008 / #013；情绪空镜旁线 → #007；竖屏钩子 / CapCut 类教程 → #001 / #002 / #009 / #010；片头系统感 UI → #011；片头字效 → #012。

需要本地样片时读 ref_reel3.mp4～ref_reel8.mp4 或各 reel-\*/source.mp4；**#001 / #002 无本地 mp4，只留链接**。

表里标「未核实」的字段不得当事实写进对外文案。

Mac 上已装剪映无界面 CLI（jianying-headless）。复刻本库 CapCut/剪映类手法时，优先走 CLI 出片。

**怎么快速用**

先看 **§2 总表** 定编号 → 再跳 **§3 / §6 详卡** → 最后用 **§4 Agent 速查** 按手法反查。

交片前自检：有没有把原片画面/BGM 当模板？关键帧是不是横拼图而不是竖排长串？
