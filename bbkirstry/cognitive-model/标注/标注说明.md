## 字段定义

每条标注对应训练集中的一条材料，字段如下。

| 字段 | 含义 |
|---|---|
| `item_id` | X 为帖子 ID；飞书为文件名 |
| `source` | `x` 或 `feishu` |
| `date` | 北京日期；飞书无明确文件名日期则为「日期不明」 |
| `kind` | X 的 post_type（original / article / long / self-thread / reply / quote / retweet）；飞书为「飞书文章」或「飞书表格」 |
| `title` | 飞书篇名；X 帖为空 |
| `path` | 训练集材料路径（X 指向私有补全 JSON 中的该 id） |
| `responds_to` | ① 她在回应什么问题、情境或对象 |
| `decompose` | ② 她怎么拆解：先看什么、分成哪几块 |
| `tradeoff` | ③ 怎么取舍：选了什么、放弃什么、理由 |
| `conditions` | ④ 成立条件：什么前提下这么判断、什么情况下会反过来 |
| `quote` | ⑤ 原文短引，不超过 40 字，逐字出自材料 |
| `quote_source` | 出处：`日期 / 帖子ID` 或 `日期 / 篇名` |
| `skipped` | 是否跳过 |
| `skip_reason` | 跳过原因；未跳过则为空 |
| `annotator` | `agy-init` 初标 / `human-fix` 抽查修正 / `rule-skip` 规则跳过 |

读不出来的字段一律写「原文未体现」，不靠猜测补全。
