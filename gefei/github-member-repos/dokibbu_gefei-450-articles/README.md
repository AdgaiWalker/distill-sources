# 哥飞出海实战文库全景分类索引与阅读笔记工作台

> 🚀 汇集海外独立开发者、出海创业者「哥飞」社群 449 篇高价值实战干货文章，涵盖海外爆款案例拆解、关键词挖掘与 SEO、广告变现与出单、建站开发与部署、AI 应用实操等核心领域。
>
> 专为出海学习打造的双栏沉浸式阅读器，支持一边深度阅读文章，一边记录实战灵感与要点，本地自动持久化保存，换篇自动切换，永不丢失。

---

## 🌟 核心功能特性

### 1. 全景目录与多维筛选系统
- **六大核心业务分类**：
  - 🔍 **爆款与优秀网站案例拆解**（167篇）：剖析海外单月数万美金产品的流量来源、商业模式与增长路径。
  - 📈 **实战复盘、新手成长与出海心路**（104篇）：踩坑总结、从 0 到 1 破零出单、独立开发者心路历程。
  - 🚀 **SEO流量、关键词挖掘与外链**（81篇）：低竞争高价值关键词筛选、外链建设、谷歌排名优化秘籍。
  - 💰 **商业变现、广告收益与支付出单**（55篇）：Stripe、Paddle、AdSense、出海支付与广告单价优化。
  - 🛠️ **技术建站、开发部署与域名运维**（22篇）：Next.js、Vercel、Cloudflare、域名选择与架构设计。
  - 🤖 **AI应用、效率工具与提示词实操**（20篇）：利用 AI 提效、Claude Code、Cursor、Sora、批量建站工具实操。
- **全文与拼音实时检索**：支持对标题、标签、关键词进行毫秒级模糊匹配搜索，支持按 `/` 键秒级聚焦搜索框。
- **年份与状态筛选**：支持按 2025 年、2026 年快速过滤；支持按「未读」、「已读」以及「📝 已记笔记」精确定位。
- **视图一键切换**：支持「卡片网格」与「紧凑列表」双视图自由切换。

### 2. 双栏沉浸式学习工作台
- **左侧：【1 查看文章】**
  - 铺满视口全屏展开，无边框黑边干扰，纯净沉浸式阅读；
  - 顶部常驻文章分类标签、年份编号、已读未读打卡按钮；
  - 支持键盘快捷键一键切篇（`←` / `→` 或 `[` / `]` 换篇，`M` 键快速标记已读，`ESC` 键关闭）。
- **中间：【自由拖拽分栏拉手 & 悬浮折叠按钮】**
  - 鼠标拖拽两栏分界线，可自由无级调节左侧文章与右侧笔记的宽度比例（自动记忆您喜好的宽度）；
  - 分栏条正中央配有精致的**悬浮折叠拉手**：点击一键向右折叠笔记，文章立即 100% 满屏展示；
  - 折叠后右边缘常驻高亮展开拉手，点击瞬间恢复，随时随地召回笔记面板。
- **右侧：【2 记笔记 & 实战沉淀】**
  - **每篇独立笔记**：为文库中的每一篇文章配备专属笔记库，换篇时自动保存当前笔记并无缝切换记忆；
  - **实时防抖自动保存**：打字过程自动保存到本地 `LocalStorage`，关闭网页或刷新绝不丢失；
  - **专属出海实战模板**：
    - `💡 灵感`：一键插入出海灵感引用块；
    - `🎯 要点`：快速提炼核心认知与选词思路；
    - `🚀 行动`：生成待落地行动 TODO 清单；
    - `📋 模板`：生成结构化复盘模板（核心要点、出海启发、落地清单）；
  - **便捷导出与复制**：
    - `📋 复制`：一键复制当前文章笔记文本到剪贴板；
    - `📥 导出`：将当前文章学习笔记一键导出为标准的 `.md`（Markdown）文件。
- **笔记状态全景联动**：
  - 凡是记录过笔记的文章，在主界面的卡片与列表上均会自动点亮 `📝 笔记` 徽章；
  - 顶部的状态筛选下拉框中支持直接筛选「📝 已记笔记」，一键汇总全部成果。

### 3. 用户体验与系统设计
- **学习进度看板**：实时计算已读篇数与百分比进度，助您掌握出海实战知识学习节奏；
- **深浅色双主题**：精心调优的极客暗夜黑（Dark）与明亮清爽白（Light）主题，一键无缝平滑切换；
- **纯原生零依赖**：基于原生 HTML5 + CSS3 + Vanilla JavaScript 构建，无需安装 node_modules，秒级加载，完全支持本地离线打开。

## ☁️ 部署到 Cloudflare Pages 指南

本项目为纯静态前端项目，非常适合使用 **Cloudflare Pages** 进行全球 CDN 免费托管与极速访问：

### 部署步骤：

1. **推送到 GitHub 仓库**：
   - 登录您的 GitHub 账号（`doki-bbu`）；
   - 新建一个公开或私有仓库，例如 `gefei-450-articles`；
   - 将本项目代码全部提交并推送到该仓库中。

2. **登录 Cloudflare 控制台**：
   - 打开 [Cloudflare Dashboard](https://dash.cloudflare.com/) 并登录；
   - 点击左侧导航栏的 **「Workers 和 Pages」** -> **「概述」**；
   - 点击右侧的 **「创建应用程序」** -> 选择 **「Pages」** 标签页。

3. **连接 GitHub 仓库**：
   - 点击 **「连接到 Git」**，授权并选择您的 GitHub 仓库（`doki-bbu/gefei-450-articles`）；
   - 点击 **「开始设置」**。

4. **构建与部署配置（零配置）**：
   - **项目名称**：自定义（如 `gefei-articles`）；
   - **生产分支**：`main`；
   - **框架预设**：选择 `None`（无）；
   - **构建命令**：**留空**（无需构建）；
   - **构建输出目录**：填写 `./`（或者留空表示项目根目录）。

5. **点击「保存并部署」**：
   - Cloudflare Pages 将在数十秒内完成部署，并分配一个全球 CDN 加速的 `*.pages.dev` 访问域名；
   - 之后只要您在 GitHub 上有新的提交，Cloudflare Pages 会自动触发持续集成并更新上线！

## ⌨️ 快捷键指南

| 快捷键 | 功能描述 |
| :--- | :--- |
| <kbd>/</kbd> | 快速聚焦到主界面的搜索输入框 |
| <kbd>→</kbd> 或 <kbd>]</kbd> | 阅读器模式下切换到 **下一篇** |
| <kbd>←</kbd> 或 <kbd>[</kbd> | 阅读器模式下切换到 **上一篇** |
| <kbd>M</kbd> | 阅读器模式下将当前文章标记为 **已读/未读** |
| <kbd>N</kbd> | 阅读器模式下快速 **折叠/展开右侧笔记面板** |
| <kbd>ESC</kbd> | 退出沉浸式阅读器，返回主索引页面 |
