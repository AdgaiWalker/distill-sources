跟谷歌Adsense部门台湾新客经理有了一个小时的语音交流，确实解答了我的大量疑问，我等下整理出来，分享给大家。

前几天搞定了，就是图里这位帮忙提交的工单




最近有至少两位群里朋友收到了这样的骗子邮件，大家可以不用理会。

今天下午2点，我与谷歌Adsense部门在台湾办公室的客户经理Nika进行了1个小时的交流。 经过这次交流，解答了我关于Adsense的很多疑问，今天的#哥飞小课堂 ，就跟大家分享一下。

首先，我感谢了 Nika 帮忙提交工单，帮助我解决了我的个人账号因为误填了公司收款信息而被要求提交资料重新核查的问题。 当时我知道问题不大，因为我的流量都是优质流量，正常流量，也就是账号本身没问题，只是因为信息变更，触发了信息验证。 这个验证要求10天内完成，否则就中止我的账号服务。 最开始几天，我都没慌，按照邮件要求，提交了表单。不过刚好遇上了年末，很多谷歌的员工放假了，导致我的信息一直卡在审核阶段。 而系统邮件又在不断的倒计时，告诉我，还剩7天就要中止服务了，还剩3天……，还剩1天……。

到了上周日，我还慢悠悠的，因为相信谷歌会正常审核。反倒是知道了情况的良辰美着急起来了，帮我找了大量的信息，最后我们判断，问题的确不严重，但是需要有人工介入，在系统倒计时结束之前给审核完成。 我周日晚上，找了谷歌的大量相关邮箱，发送了邮件，说明了情况，但是都没有收到后续邮件。 周一早上，我开始有点着急了，在朋友圈、即刻、推特上都发了相同的信息，请求有能够接触到谷歌的人帮忙牵线，请求人工介入加急审核。

最开始，有朋友联系了谷歌Ads的员工，还有朋友联系了谷歌云的员工，以及其他更多别的部门的员工，都说不好办，他们插手不上Adsense的事情，只能代为内部联系Adsense部门的人。 直到周一下午2点，群里的朋友 Joanne 帮忙把情况转发给了 Nika，这才真到专业对口的人，Nika 了解清楚情况后，让我打开表单，再次提交了个人信息，她拿着表单ID，去帮我提了工单，加急了审核。 到了周二早上，我就收到了谷歌系统发来的邮件，说资料审核通过了，我悬着的心终于放下了。

好的，现在说回下午主要交流的内容，我主要是问了 Nika 几个问题，都得到了满意的解答，下面我一个一个问题来说。

1、个人账号和企业账号是否可以变？ 答案是不能变，最开始注册好了是什么类型的账号，后面就不能改了。 假如你一开始是个人账号，后面想用公司信息收款，就需要注册一个新的账号。 并且也同样要做好账号隔离，不要让系统认为你一个人在操作多个Adsense账号。

2、个人账号和企业账号的本质区别是什么？ 答案其实没区别，只是收款信息的区别。 也就是，如果用接收Pin码的形式来验证账号的话，两者的验证方式都是一样的，只要能够收到Pin信件，谷歌不管你是个人地址，还是公司注册地址都行的。 但是假如你多次收不到Pin信件，最后通过在线表单形式提交信息验证的话，如果你是个人信息注册的，就需要上传你的身份证，以及你跟你填写地址之间的关系。举例你现在住的地址不是身份证地址，那么就可以补充信用卡账单的地址来证明这个地址是你在使用的。 而如果是企业账号，补充的信息，就需要是营业执照地址，水电账单地址等一致。

3、同一个网站，既出现在新注册的账号，也出现在老账号，是允许的吗？ 其实谷歌是允许这种情况出现的，举个例子，有些网站，会把一些栏目交给代理去运营，那么这些网站一个域名下就会出现多个发布商的广告，这是正常的。 只要你不是特别离谱，举例一个网站下出现了十几个发布商广告这样的异常情况，那都是没问题的。 谷歌不会因为这样的原因，就给你封号。 也就是说，我们已经有一个账号的情况下，如果再注册一个新账号，举例是企业账号，那么把某些网站迁移到新账号去投放完全没问题。

4、有多个账号时，需要做好隔离吗？ 理论上，谷歌Adsense只允许一个身份注册一个账号。所以很有必要做好隔离。 注意浏览器环境，注意IP地址等信息，不要在一个浏览器里同时登录多个账号，需要做好隔离，否则可能会触发风控，导致被提醒一个人拥有多个账号。

5、新注册的账号，是否容易因为突然大量流量而被限制投放？ 这是有可能发生的，但是谷歌也会看流量的质量，一般新账号前几天会被限制投放，等到慢慢机器学习到了你的网站流量情况后，就会放开了。 我提问说，有好些朋友遇到被限制了两周或者更久。 Nika回答说，也是有可能的，这些都是算法在控制，如果算法发现你的流量有异常，举例新账号、新网站，又有突发的大流量，而且流量还不稳定，时高时低，那么就比较容易触发风控。

6、为什么老账号就不会被限制投放呢？ 不被限制的是优质的老账号，那些流量质量不高，乱搞的老账号一样会被限制，甚至被封号。 优质老账号通过过去的流量质量已经向谷歌证明了，这是一个值得信任的账号，所以老账号下添加的新网站，突然有了大流量，也会给出一个初始的值得信任的信号。 之后，谷歌会不断基于流量质量对账号、对网站进行评分。所以如果老账号做了不好的事情，也是会被惩罚的。

7、怎么解决新账号被限制投放问题？ 基本还是靠养号。 谷歌也需要对广告主负责，你的流量价值高，你在赚钱的同时，广告主得到了优质的流量，他们就愿意花钱，与此同时，谷歌作为一个平台也在赚钱，所以这是一个三赢的事情。 你通过源源不断的流量，向谷歌证明了，你这个账号下的流量质量高，那么你的账号后面被限制的问题就会越来越少。

特别说明下，以上文字，都不是对话的原文，是我基于我自己的理解后，重新描述出来的。

这里Nika也说了，新账号，可以报备到她那里去，相当于用她的信用背书，让账号尽可能不被限制投放，尽快恢复到正常的填充率。 不过初期，她说先拿我将要注册的企业账号来测试。 先合作，后面再来扩大报备的账号的范围。

8、新账号是不是一开始广告单价都比较低？ 是的，因为新账号，一切都是新的，谷歌一开始不可能给你填充高质量高单价的广告。 你需要通过高质量流量来养号，通过源源不断的流量来向谷歌证明，你是一个优质的发布商，你是一个值得信任的发布商。 经过这么多年的发展，Adsense已经是一套无比复杂的系统，里边大量运营了机器学习来判断流量、判断网站、判断账号质量。 总之，只要你是准备好好长期做事的，那么最初的低价时期是会过去的。

9、对于我们目前社群里这种，发现谷歌搜索的新词，做一个网站，然后靠Adsense变现的模式，怎么看待？ 先说从谷歌生态的角度，我们能够找到还没有被很好满足的需求，然后做一个网站去满足搜索需求，这是谷歌愿意看到的事情。 但是一定要从用户的角度去做好网站，真正的帮助到用户，并且做好长期的品牌建设，不要做一些短视的事情。 我说，放心，谷歌的搜索排名算法精明得很，我们如果满足不了用户的搜索需求，谷歌直接就不给我们排名，不给我们流量了。 再说Adsense变现，谷歌不希望看到，你做一个新网站，目的就是为了短期赚钱，更希望看到说，你这是一个愿意长期维护运营下去的网站，你是一个品牌，这样优质的广告主的高单价的广告才有可能被显示到你的网站里。

10、你们是怎么看待Adsense套利的？ 我们有一些产品，如谷歌搜索，其实本意是为了帮助那些内容资讯网站、电商网站在用户有搜索需求的情况下，在搜索结果里显示广告，帮助网站更好的变现。 但是这个玩法，别一些人玩坏了，所以我们封掉了大量的不合规账号。 产品组那边后续做一些尝试，也会更加的谨慎。 我们更期待大家共赢的玩法，而不是这种短期套利，只是为了赚钱的做法。 从长期来看，如果我们不打击这样的情况，那么广告主的钱就会花得不值，他们就不会继续投放广告，那么大家都没钱赚了。 生态很重要，广告主、发布商、谷歌，三方应该是合作共赢的。

11、同一个老账户下，不同的网站广告单价也是不一样的。 这是正常的，因为不同网站背后的流量人群不一样，那么就会导致被显示出来的广告不一样，所以单价也就不一样了。 谷歌在努力的去实现，让每一个广告都能够出现在合适的网站，合适的用户面前。 广告单价不是人为控制的，是机器学习你的流量价值后，给你显示不同的广告后综合计算出来的。 流量价值越高，广告单价就越高。 流量的需求价值越高，广告单价就越高。

12、最近一些国内人抱怨说账号审核老是不通过，但是我社群里的朋友们都还挺容易过审的。 是的，这还是跟流量质量和网站质量有关系。 尤其是新账号的第一个拿来审核的网站，我们更是会基于各种数据指标来判断。 审核不仅仅是人在审核，还包括机器审核，也就是算法会去判断你的流量质量。 如果你的网站不好好做，如果你的网站几乎没流量，如果你的网站流量质量差，那么的确是不太容易被审核通过。

13、我的H5游戏站，可以申请激励广告吗？ 我们需要审核你的网站之后再来判断。
