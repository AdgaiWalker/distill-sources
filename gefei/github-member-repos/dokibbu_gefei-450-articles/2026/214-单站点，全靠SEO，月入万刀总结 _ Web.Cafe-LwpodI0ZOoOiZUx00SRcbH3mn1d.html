最近一个网站纯靠SEO实现了月入万刀，这里分享一下个人的操作经验，不一定完全正确，也不一定适合所有人，有不对的地方，希望能够得到大家的指点。

1. 怎么找需求

从 Similarweb 开始，去找那些已经有一定流量、已经在赚钱，但是竞争还没有那么激烈的网站。 先看它的流量从哪里来，是自然搜索、广告，还是社交媒体。如果一个网站大部分流量都是靠广告买来的，SEO 又做得比较差，最好上线时间不是很久的网站。我会觉得这里面可能有机会。

2. MVP 怎么做

确定要做以后，我会先让 Claude 把竞争对手的网站分析一遍。包括它有哪些功能、用户使用流程是什么、哪些功能需要付费、价格怎么设置、会员有什么区别，以及整个产品大概怎么实现。然后让 Claude 根据这些功能，整理出一套完整的开发方案。我最开始只是把核心功能做完，但是相对参考网站我会在免费使用以及用户使用流程方面去做一些大的优化。

3. 不断增加内页和 Blog

网站上线以后，就开始不断增加内页和 Blog。内页最好还是围绕核心功能去做。比如你做的是一个 AI 图片网站，那就围绕不同的使用场景这些方向去增加页面。这些页面带来的流量不一定最大，但是用户精准。有些内容看起来搜索量很高，也确实可以带来流量，但是和产品关系不大，最后基本不会转化。

4. 外链非常重要

外链是我认为比较重要的一部分，尤其是新网站前期。一个新站没有权重，也没有品牌，很难获得流量，当然新词可能可以。所以前期我一般会花钱买比较多的外链。前期的外链更看重数量和覆盖面，等到网站流量和排名开始起来以后，买外链的速度可以慢一点，但是质量要稍微提高。

5. 经常看 GSC 和 Bing 后台

网站上线以后，GSC 和 Bing Webmaster Tools 要经常看。现在可以让 Claude 通过 MCP 连接这些后台，直接读取数据，然后让它分析哪些页面有问题，哪些关键词值得继续优化。需要注意的是已经上线很久，而且已经有稳定流量的页面，不要随便大改。按照飞哥的方法，已经上线的页面每次只改一两个单词，然后观察变化。

6. 最后总结

网站上线前SEO的基础必须打牢固，按照飞哥交给我们的方案，上线前完整检查一篇，然后不断的发外链，前期看量，质量当然也要考虑，spam的就不要发了，浪费钱。但是这些的前提是一定要找准需求。

然后就是要有耐心，要给一定的时间给自己的网站。

有一定的SEO基础之后，我个人觉得先把一个网站做精，再去考虑做第二个，第三个, 因为一个人的精力实在有限，高手除外。
