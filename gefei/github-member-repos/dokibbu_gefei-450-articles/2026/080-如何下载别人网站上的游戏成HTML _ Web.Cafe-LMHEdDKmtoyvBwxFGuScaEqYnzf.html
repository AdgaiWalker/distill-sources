有时候会遇见别人网站上的游戏找不到它的资源来处，或者反 ifame 很强。直接用 ctrl+s 下载的有时候游戏无法运行，这时候可以用到 wget2 了。wget2

mac 可以使用 Homebrew 安装


代码块
Bash
brew install wget2

在 devtools 找到别人 iframe 的链接，然后在命令行使用


代码块
Bash
wget2 -p -k -E https://sloperun2.io/slope-run.embed

就能得到单个html，之后无论是放到 cloudflare R2 还是哪里都随各位愿了。

有时候别人不想告诉你他们是从哪里拿到的资源，打开html文件也能发现来处。例如上面示例网站，自己包装了一下。但打开下载的html，就会看到


代码块
HTML
frame_game.setAttribute("src", "https://azgames.io/slope.embed");

直接去 https://azgames.io/slope ，可以看见人家直接给了 iframe 链接。https://azgames.io/slope
