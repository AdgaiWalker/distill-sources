每天可以发邮件 200 封

第一步： 部署worker

1.
点击 deploy to cloudflare，会跳到 dash.cloudflare 域名
2.
修改 DOMAINS 参数为 你的域名，其他保持默认即可，点击 Deploy

第二步：部署cloudflare access

作用：给第一步部署的 worker 配置可以登录的邮箱账号

1.
dash 页面的 zero trust，开通 0 元套餐，team domain 可以随意定，后面也可以修改。
2.
添加 application Access controls -> applications -> create new application-> 选择 self-hosted，workers，域名是第一步部署worker 后得到的子域名 https://worker_name.user_name.workers.dev/
3.
添加 policies Access controls -> Policies-> Add a policy-> 名字随便 include 选择 emails，邮箱填为你要登录的邮箱

第三步： 开启邮件发送

dash -> Email Service->Email Sending-> Onboard domain 选择用来发邮件的域名

配置完后 Status 从 Syning 变成 Enabled 才可以发邮件，需要等一段时间

第四步： 开启邮件接收

dash -> Email Service->Email Routing-> Onboard domain 选择用来收邮件的域名 点击刚刚创建的条目-> Routing Rules -> Create address-> support@domain, send to a worker，从下来列表中选择第一步部署的 worker。

catch-all 可选可不选，如果启用的话，也是发到 worker。

配置完后 Status 从 Syning 变成 Enabled 才可以发邮件，需要等一段时间

第五步： 设置 worker 的变量： POLICY_AUD 和 TEAM_DOMAIN，EMAIL_ADDRESSES

dash-> compute->workes & pages-> 选择第一步创建的 worker。

Setting -> workers.dev ->右边的三个点-> 启用 cloudflare access-> 会出现一个弹窗，写着POLICY_AUD和 TEAM_DOMAIN ，将其复制下来，然后修改对应的 Variables and Secrets。
