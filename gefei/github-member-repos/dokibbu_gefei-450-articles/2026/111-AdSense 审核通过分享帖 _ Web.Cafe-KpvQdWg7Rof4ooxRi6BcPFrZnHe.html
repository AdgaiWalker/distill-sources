踩过的一个坑：Next.js App Router 部署到 Vercel 后 ads.txt 报 500

这个坑分享给同样用 Next.js + Vercel 的朋友。

申请 AdSense 需要在网站根目录放一个 ads.txt 文件。按照常规做法，把 ads.txt 丢到 public/ 目录下就行了，但如果你用的是 Next.js App Router 并且部署到 Vercel 上，访问 你的域名/ads.txt 的时候可能会报 500 错误。

原因是 App Router 的路由匹配机制把 ads.txt 的请求拦截了，Vercel 上的行为和本地开发时不一样，本地可能没问题，部署上去就 500。

解决方法 ：不要依赖 public/ 目录，改为在 app/ads.txt/route.ts 里手动写一个 route handler 来返回内容：


代码块
TypeScript
export async function GET() {
const content = `google.com, pub-你的发布商ID, DIRECT, f08c47fec0942fa0`
return new Response(content, {
headers: { 'Content-Type': 'text/plain' },
})
}

这样 https://你的域名/ads.txt 就能正常访问了，AdSense 也能正常抓取验证。
