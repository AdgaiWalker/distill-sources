让Google找到你，并且把你排到前面。

这是新手误解最多的一环。很多人以为"网站上线了，用户就会来"。现实是：你上线一个网站，Google可能两周都不知道它的存在。就算知道了，排在第5页，等于不存在。

今天这篇，我把SEO从"玄学"拆成"工程"——每一步做什么、为什么做、怎么做，写清楚。


01 新站SEO的现实：没有捷径，但有正确路径

先说几个数据，帮你建立正确的预期：

•
93%的在线体验始于搜索引擎 ——用户不搜你，就找不到你
•
75%的用户不会点击第2页 ——排在第11名和不存在没区别
•
排名第1位获得27.6%点击率，第10位仅2.4% ——排名每下降一位，流量断崖式减少
•
新站SEO需要4-6周才能看到初步效果 ——这是Google的机制，绕不开

赫兹上线了20多个站，前3个月大部分悄无声息。直到第4个月，专注于一个有起色的站，持续优化SEO，才真正开始有流量。

龙猫21天航海拿到第一笔美元，但他的站也经历了"上线→等待→收录→有排名"的完整周期。

SEO不是玄学，是时间+正确操作的结果。

问题是：大多数人等不到结果就放弃了。要么觉得"SEO没用"，要么觉得"换个需求可能更快"。然后不断重复"开始→放弃"的循环。

今天的文章，就是帮你把这个"等待期"用正确的操作填满。


02 SEO的底层逻辑就一句话

Google是怎么决定谁排第一的？

一句话说清楚： Google要把"最好的答案"排在前面。

不是关键词最多的，不是外链最多的，不是网站最漂亮的——是对用户最有用的。

Google的算法每年更新几百次，但核心原则从来没变过。2025年最重要的排名信号体系叫 E-E-A-T ：

•
Experience（经验） ：你有第一手使用经验吗？文章里有没有"我测试了3个月""我对比了5款工具"这样的表述？
•
Expertise（专业） ：你在这个领域够专业吗？有准确的数据、清晰的解释、权威的引用吗？
•
Authoritativeness（权威） ：你的网站被其他网站引用过吗？有行业内的口碑吗？
•
Trustworthiness（可信） ：你的网站安全吗？有HTTPS、隐私政策、真实的联系方式吗？

E-E-A-T不是四个独立的评分项，是Google判断"这个答案可信吗"的综合标准。

理解了这个，你就理解了SEO的核心： 不是骗Google把你排上去，而是真的成为最好的答案。

所有SEO技巧，本质上都是在帮助Google理解"你的内容有多好"。TDK优化是让Google快速理解你的页面主题，内链建设是帮助Google发现你的更多好内容，外链建设是其他网站在告诉Google"这个网站值得信任"。

方向对了，技巧才有用。方向错了，技巧只会加速失败。


03 上线当天就要做的5件事

网站上线当天，花30分钟做这5件事。不做，等于把网站藏起来不让Google看。

第1件事：提交Google Search Console（5分钟）

Google Search Console（GSC）是你和Google之间的沟通桥梁。它告诉你：

•
Google有没有收录你的网站
•
哪些关键词给你带来了流量
•
你的网站在搜索结果中排第几
•
有没有技术问题影响排名

操作：

1.
打开 search.google.com/search-console
2.
添加你的域名
3.
选择DNS验证（最简单，只需要在域名注册商添加一条TXT记录）
4.
验证成功

这是SEO的第一步，没有之一。不做GSC，你连自己的网站有没有被Google收录都不知道。

第2件事：提交Sitemap（3分钟）

Sitemap是一个XML文件，列出了你网站上所有页面的URL。相当于给Google一张"导航地图"。

如果你用的是Next.js+Vercel，通常会自动生成。手动确认一下：

•
访问 你的域名/sitemap.xml
•
如果能看到一个XML页面，说明有了
•
到GSC → Sitemaps → 输入 sitemap.xml → 提交

第3件事：检查robots.txt（2分钟）

robots.txt告诉搜索引擎"哪些页面可以爬，哪些不可以"。

确认你的robots.txt没有屏蔽搜索引擎：

•
访问 你的域名/robots.txt
•
确保没有 Disallow: / 这样的全站屏蔽规则
•
确保有 Sitemap: 你的域名/sitemap.xml 这一行

第4件事：确认HTTPS（1分钟）

Google明确表示HTTPS是排名信号。没有HTTPS的网站，排名会受影响。

Vercel部署的网站自动带HTTPS，不需要额外配置。但确认一下：

•
访问你的网站，地址栏有没有🔒锁图标
•
如果没有，说明SSL证书有问题，检查部署配置

第5件事：手动请求索引首页（5分钟）

新站上线后，Google通常需要几天到几周才会主动发现你。但你可以主动"敲门"：

1.
GSC → URL检查
2.
输入你的首页URL
3.
点击"请求编入索引"
4.
等待（通常几分钟到几小时）

这一步能让Google更快地发现你的网站，把"等待期"从几周缩短到几天。


04 每个页面的SEO清单

上线后的每一页内容，发布前过一遍这个清单。不需要全部做到满分，但至少做到及格。

4.1 TDK：标题、描述、关键词

Title（标题）：

•
长度：50-60个字符
•
包含核心关键词，放在最前面
•
结构：核心关键词 - 修饰语 | 品牌名
•
语气：吸引点击，不是简单罗列


代码块
JavaScript
✅ Free QR Code Generator - Create & Download Instantly | ToolHub
✅ Best Image Compressor - Reduce Size by 80% Without Quality Loss
❌ Welcome to my website
❌ QR code generator online free tool

Description（描述）：

•
长度：150-160个字符
•
包含关键词+价值主张+行动号召
•
目的：让用户在搜索结果里看到时想点进来


代码块
JavaScript
✅ Generate QR codes instantly for free. Support URL, text, WiFi, and vCard.
Download in PNG or SVG. No sign-up required. Try now!
❌ This is a QR code generator website.

4.2 标签层级


代码块
JavaScript
│ ├─ H3（子部分）
│ └─ H3（子部分）
└─ H2（主要部分）

关键词分布：

•
H1：主关键词
•
H2：相关关键词
•
H3：长尾关键词

每个页面只能有一个H1。 多个H1会让Google困惑，不知道这个页面的核心主题是什么。

4.3 图片优化

•
所有图片都有 alt 属性（描述图片内容）
•
文件名有意义（ qr-code-generator.png ，不是 image1.png ）
•
使用WebP格式（比PNG小50%以上）
•
设置宽高属性，避免布局偏移（影响Core Web Vitals评分）

4.4 内链策略

内链是你网站内部页面之间的链接。作用有两个：

1.
帮助Google发现和理解你的更多页面
2.
帮助用户在你的网站上浏览更多内容（降低跳出率）

规则：

•
每页有2-5个内部链接
•
锚文本要有描述性（✅"QR code generator" ❌"点击这里"）
•
链接到相关内容，不是随机链接
•
检查是否有死链（404页面）

4.5 结构化数据

结构化数据是一种告诉Google"这个页面是什么类型的内容"的标记方式。添加后，你的搜索结果可能会显示额外的信息（星级评分、FAQ折叠、价格等），更吸引点击。

工具站最常用的结构化数据类型：

•
WebApplication ：告诉Google这是一个在线工具
•
FAQPage ：如果你有常见问题部分
•
HowTo ：如果有教程步骤

添加方式：在页面 <head> 中插入一段JSON-LD代码。


05 工具站的SEO和内容站不一样

很多人学SEO，照搬的是内容站（博客）的方法论。但工具站的SEO策略和内容站完全不同。搞混了，会走很多弯路。

内容站的SEO

内容站靠 文章矩阵 获取流量：

•
围绕核心主题写大量文章（几十到几百篇）
•
每篇文章针对1-2个关键词
•
通过内链网络把文章串联起来
•
竞争对手是其他博客和内容网站

典型例子：Wirecutter（产品评测站）、NerdWallet（金融知识站）

工具站的SEO

工具站靠 工具页+周边内容 获取流量：

•
核心是工具页面本身（用户直接使用工具）
•
围绕工具写博客文章（"how to create a QR code""what is image compression"），为工具页引流
•
每个工具页就是一个小型的"着陆页"，需要独立优化TDK和内容
•
竞争对手是其他工具网站

工具站最有效的SEO策略：写围绕工具的博客文章，用博客文章的长尾关键词流量，引导用户到工具页。

举个例子：你做了一个QR Code Generator工具。

•
工具页TDK优化："Free QR Code Generator"
•
博客文章："How to Create a QR Code for Your Business"（长尾词）
•
博客文章："QR Code vs Barcode: Which One Do You Need?"（对比类长尾词）
•
博客文章："5 Creative Ways to Use QR Codes in Marketing"（场景类长尾词）
•
所有博客文章都链接回工具页

这就是赫兹说的"低KD多内页"打法——不是靠一个大词打天下，而是靠大量低竞争的长尾词聚沙成塔。

赫兹的一个站只有8条外链、KD为0，但通过大量低KD长尾词内页，拿到了 41K月访问量 ，Google排名第二。


06 出海新手最容易犯的6个SEO错误

错误1：上线后什么都不做，干等流量

"网站做好了，等Google收录就好了。"

Google不知道你的网站存在。你需要主动提交GSC、提交sitemap、手动请求索引。不敲门，Google不会自己找上门。

错误2：关键词堆砌

"标题里多塞几个关键词，排名会更高。"

2026年了，Google的算法比这聪明得多。关键词堆砌不仅不会提升排名，还可能被判定为spam，反而降权。

正确做法： 关键词出现在自然的位置（标题、第一段、H2标签），密度控制在2-3%。

错误3：忽略移动端

Google已经实行 移动优先索引 ——它主要看你的网站在手机上的表现来决定排名。

如果你的网站在手机上显示混乱、文字太小、按钮点不到，排名一定上不去。

正确做法： 每个页面上线前，用手机打开看一遍。或者用Chrome开发者工具切换到移动视图检查。

错误4：不做内链

很多新手的网站是"孤岛"——每个页面独立存在，互相没有链接。

这等于告诉Google："这些页面之间没有关系。"而且用户也无法在你的网站上浏览更多内容。

正确做法： 每个页面至少有2-3个内部链接，锚文本有描述性。

错误5：频繁改版

"这个页面排名不好，我重做一下。"

频繁修改页面URL、标题、内容结构，会让Google的索引混乱。每次大改都可能丢失已有的排名。

正确做法： 页面上线后，小修小改可以（改文案、加内容），大改要慎重（改URL、删页面）。如果必须改URL，做好301重定向。

错误6：买了外链

"花点钱买几十条外链，排名应该能上去。"

2026年，Google识别和惩罚购买外链的能力非常强。被查到，轻则排名下降，重则整站被K。

正确做法： 通过优质内容自然吸引外链。新站可以先做几条"安全外链"：Hacker News提交、Chrome插件商店（DR99）、导航站收录。


07 什么时候能看到效果？

这是新手问得最多的问题。给你一个真实的时间线：

第1-2周：收录期

•
手动请求索引后，Google会在几天内收录你的首页
•
检查方法：GSC → 索引 → 页面 → 搜索你的域名
•
如果收录了，恭喜，第一步完成
•
如果没收录，检查robots.txt、检查SSR（服务端渲染）、检查是否有noindex标签

第4-6周：初步排名期

•
收录后，Google开始评估你的页面质量
•
这个阶段你可能在第50-100名，搜索你的关键词可能翻好几页才能找到
•
这是正常的。 不要因为看不到排名就改来改去
•
继续发布内容、优化现有页面、获取外链

第2-3个月：稳定排名期

•
如果你的内容质量过关，排名会逐渐上升
•
长尾关键词可能先有排名（因为竞争小）
•
主关键词可能还在10-20名
•
开始有少量自然搜索流量

第6个月：长尾流量起量期

•
大量长尾词页面开始贡献流量
•
如果做了几十个内页，每个页面每天几个到几十个访问，累计起来就很可观
•
赫兹的41K月访问量，就是靠大量低KD内页聚沙成塔

一个真实案例

赫兹的出海时间线：

•
2025.08：开始上线网站
•
2025.09-10：20多个站大部分没声响，焦虑期
•
2025.10：一个站开始有起色
•
2025.11：专注优化，月收入990美元
•
2026.02：月收入突破4000美元

从上线到月入千刀，赫兹花了4个月。 其中前3个月几乎没有收入。但他没有放弃，而是持续优化、持续学习、持续发布内容。

SEO是复利游戏。 前期的积累看起来很慢，但一旦突破临界点，流量和收入会加速增长。


08 SEO不只是一套技术，是一种思维

到这儿，你可能觉得SEO就是一套操作清单——做TDK、做内链、做外链、等排名。

这些技术操作当然重要。但更重要的，是SEO背后的一种思维方式。

用户意图优先

用户搜索"QR code generator"，他不是想看一篇关于QR码历史的文章。他想要一个工具，输入文字，生成二维码，下载。

SEO的第一原则：理解用户搜这个词时想要什么，然后给他最好的答案。

三木把搜索意图分了四类：

•
信息型 （how to、what is）→ 写教程、写指南
•
商业调研型 （best、top、vs）→ 写评测、写对比
•
交易型 （buy、price、discount）→ 写购买指南
•
导航型 （品牌名、产品名）→ 确保品牌词排名第一

不同意图对应不同内容。用户搜"best QR code generator"时，给他一个工具列表评测；搜"how to create a QR code"时，给他一个步骤教程。

数据驱动迭代

SEO不是"做完就完"的事，是持续优化的过程。

每周看GSC数据：

•
哪些关键词带来了流量？
•
哪些页面排名在上升？
•
哪些页面有展现但点击率低？（说明标题或描述不够吸引人）

每月做一次全面审计：

•
有没有死链需要处理？
•
有没有新发现的排名机会？
•
竞品有没有超过你？

用数据决定下一步做什么，不要凭感觉。

长期主义

SEO和出海一样，是种树，不是种草。

种草：今天种，明天就能拔起来看效果。 种树：今天种，明年才能吃到果子。但一旦结果，年年都有。

赫兹说：" 心力是最重要的能力。 "SEO半个月没流量不放弃、页面没收录不焦虑、排名掉了不崩溃——这些都需要心力。

哥飞的种树理论：种足够多的果树（多站矩阵），总会有收获的季节。但前提是，你得种下去，然后等。

急不得。但也不能什么都不做地等。

正确的节奏是： 上线→提交GSC→发布内容→获取外链→每周检查数据→持续优化→等待结果。

每一步都在推进，每一天都在积累。这就是SEO的正确打开方式。


09 今天就能做的3件事

不管你的网站上线了没有，这三件事现在就能做：

1. 注册Google Search Console → search.google.com/search-console，用Google账号登录。后面所有SEO工作都从这里开始。search.google.com/search-console

2. 安装一个SEO检查插件 → AITDK插件（免费），可以一键检查任何网页的TDK、SEO健康度、流量来源。去竞品网站点一下，看看他们的SEO做得怎么样。

3. 用Google搜索你的目标关键词，分析前5名 → 不要急着做网站，先看看排在前面的网站是怎么做的。他们的Title怎么写的？内容覆盖了哪些点？有什么他们没覆盖的角度？

先看懂战场，再决定怎么打。
