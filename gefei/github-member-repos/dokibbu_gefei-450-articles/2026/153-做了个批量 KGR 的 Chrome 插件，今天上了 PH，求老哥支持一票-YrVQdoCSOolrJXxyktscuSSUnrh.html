哥飞经常推荐用 KGR（Keyword Golden Ratio） 来判断一个词值不值得做，尤其适合新站、出海站找「竞争相对小、又有搜索量」的机会。

我自己也一直在用，但词一多就头疼：每个词要查 allintitle 结果数，再去 Keyword Planner 拉搜索量，最后手算 KGR、排序筛选——几个词还能忍，上百个就明显拖效率了。

于是做了 EagleKGR ，一个自动化批量 KGR 查询和计算的 Chrome 浏览器插件 。

大致思路

1.
对每个词自动发起 allintitle 搜索，抓取结果数
2.
针对 Google 异常流量监测，做了 模拟人工 的处理：页面滚动 + 随机时间间隔，降低被风控的概率
3.
在 Keyword Planner 里 一键抓取 这些词的月搜索量
4.
自动合并数据、计算 KGR，得出这个词是否值得做的结论
5.
支持排序、批量导出，方便后续选题和铺内容

免费使用。
