Chatgpt Plus 每月订阅费用20 美元，订阅后用户可以使用Codex。

Codex 很强，但是额度是真的不够用啊，今天用了一会，额度就只有不到 50%了。


用完就只能等，要么付费买额度，或者直接订购Chatgpt Pro。

实际上Chatgpt 本身的聊天模式就已经非常强了，搭配一些“邪修”用法，完全可以达到 Codex 平替的效果。

使用姿势介绍

首先在Chatgpt聊天界面-插件模块安装Github 仓库,并完成登录授权.


然后在对话里，就可以引用你的项目仓库，直接让 chatgpt 进行开发任务。 根据你的需要，可以直接在 main 分支开发，也可以单独拉新分支，也可以创建 PR。

Github 免费用户拥有一定的github action额度，这个可以直接在 Github提供的虚拟机环境里跑编译。

开发完了，可以在本地电脑里拉分支，然后验证一下。


进阶玩法1

还有一个骚操作，就是连接Remote Desktop Commander 这个插件。这个插件哥飞之前有介绍，这样就可以连接你的本地电脑了。



实际测试，发现可以做到:

1.
接管本地的命令行操作，可以实现chatgpt操控github 开发,然后再本地拉代码，运行，打开浏览器。

进阶玩法2

出门在外的话，可以再下载一个 UU远程 ，这样就能用手机控制了。

进阶玩法 3

可以直接让chatgpt生图，然后更新到 github仓库空间里，这样可以白嫖 图像生成的额度，这个好像和codex也是互相独立的。

小结

如果预算充足,当然是直接跑 Chatgpt Pro，甚至 api模式接入了。但是如果像我一样，日常用量可能就是 2-3个 chatgpt Plus，这个模式可以试一试。哈哈哈。

目前按照这个方案上了一个站，游戏 wiki 站，效果还可以哈。我是先让它在github里把仓库模版初始化、做了很多精简。然后做了前几个版本。


用了很长时间，似乎额度都是充足的，完全没有 token 消耗焦虑。
