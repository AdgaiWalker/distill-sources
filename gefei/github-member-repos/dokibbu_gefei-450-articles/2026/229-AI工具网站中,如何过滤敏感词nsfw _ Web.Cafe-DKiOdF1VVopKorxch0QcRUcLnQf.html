我们在做AI工具网站中经常会遇到 nsfw 合规问题,

下面分享一下,我的解决方案,

第一种方案写死数组,在数组加入敏感词,


代码块
JavaScript
'violence', 'suicide', 'kill', 'terrorist', 'bomb', 'weapon'
]

当遇到这些敏感词的时候,可以惊喜逻辑判断

第二种方案是使用开源项目(我一直在用),对服务器有一定的要求(4G内存就可以了)

下面分享如何使用这个项目 项目是基于docker 搭建,(没有docker基础可以简单学一下很简单) 服务器需要安装 git 以下是使用这个项目


代码块
JavaScript
git clone https://github.com/KOKOSde/localmod.git

docker build -f docker/Dockerfile -t localmod:latest .

docker run -p 8000:8000 localmod:latest

安装完成之后;如何使用 第一种方式,关于prompt 是否敏感,我的项目是基于php的,以下是示例代码


代码块
JavaScript

下面是图片是否敏感


代码块
JavaScript
$apiImage = "http://xxx:8000/analyze/image";
$imageData = [
"image_url" => $pic
];

$imageResult = postJson($apiImage, $imageData);

if ($imageResult) {
$imageResultArray = json_decode($imageResult, true);
// 👈 顺便把你的 == 改成了宽松的类型安全判断，或直接 if (!empty($imageResultArray['flagged']))
if (isset($imageResultArray['flagged']) && $imageResultArray['flagged'] == true) {
return [
'success' => false,
'code' => 'COMPLIANCE_BLOCKED',
'message' => 'Compliance Notice: The uploaded image violates our safety and content moderation policy.'
];
}
}
