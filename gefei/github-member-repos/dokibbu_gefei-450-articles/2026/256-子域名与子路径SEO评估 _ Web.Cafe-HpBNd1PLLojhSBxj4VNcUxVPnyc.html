写了自己关于子域名(subdoamin)和子路径(subfolder)的理解，希望大家能多多指出错误和遗漏的地方

在搭建网站时,一个常见的技术决策是一个新板块放到子域名（blog.example.com），还是子路径（example.com/blog）中？blog.example.com example.com/blog

很多团队误以为“子域名是域名的所属关系”，所以为了业务区分或部署方便选择子域名。然而从 SEO 的角度，子域名并不是严格所属，甚至可能是竞争关系。

Hostname 才是竞争主体

要理权重传递，首先要理清几个网络基础概念：

•
主域名（Apex Domain / Root Domain） ：如 example.com
•
子域名（Subdomain） ：如 blog.example.com
•
主机名（Hostname） ： example.com 和 blog.example.com 是独立的 hostname
•
子路径（Subfolder / Subdirectory） ：如 example.com/blog


搜索引擎进行索引（index）和排名（rank）的最小竞争主体是hostname。

算法不会因为 blog.example.com 背靠 example.com ，就把主域名的历史权重全部注入子域名.同样，在同一个关键词搜索结果页（SERP）上，他们依然被视作独立，需要相互竞争。blog.example.com example.com

家族成员 vs. 全能个体

将子域名和子路径两种结构具象化为人，可以更直观比较竞争优劣:

子域名结构 = 家族（主域名）+ 家族成员（子域名） 。资源被分配给各个家族成员。

每个新成员出身都带有家族背景加成，成功会反哺家族.但每个成员都会分走一部分家族资源，需要独立积累外链和排名。家族背景加成非常短暂，最终还是由该成员能力决定。

子路径结构 = 个人（域名）+ 能力（子路径） 。一荣俱荣一损俱损。

每项垂类扩展，都直接提升个体能力，在搜索排名中得分越来越高。但是一旦某个板块被处罚，所有排名都会降低。同时不利于横向扩展，业务跨度过大容易被认为多而不精。


基于上述具象化，搜索结果排名中， 无论是来自家族的成员，还是单打独斗的个体，都要在同一个规则下一起竞争。 （当然，同一个家族的其他成员可以选择在该类别中弃权）。

问题在于：同一类别，即每个关键词是个人赛，但是比赛内容考核得却是全方面的综合能力，高度分工、掌握单一能力的家族成员很难与掌握全方位能力的个体竞争。

什么时候可以用子域名

业务功能完全异质、不相关 .例如 google.com 和 mail.google.com 。前者负责搜索业务，后者负责邮箱业务,两者场景和目标人群完全不同。google.com mail.google.com

不参与公开排名，不需要SEO 。例如 notion.com 和 app.notion.com 。前者官网、宣传与门面，负责收割SEO 流量。后者是高度个性化的 SaaS应用后台，内容私密且不需要搜索引擎索引。notion.com app.notion.com

技术栈彻底无法统合或存在 UGC 风险隔离 。例如 notion.com 和 notion.site 。前者是主站，后者存放 UGC 内容。当子板块包含大量用户生成内容（UGC），存在被垃圾链接污染并导致降权的风险时，用子域名将风险隔离在主站之外。notion.com
