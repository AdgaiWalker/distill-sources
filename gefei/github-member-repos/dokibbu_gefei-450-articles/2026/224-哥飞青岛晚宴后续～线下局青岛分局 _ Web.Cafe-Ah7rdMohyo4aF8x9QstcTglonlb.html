第二次参加青岛线下局了，先谢谢哥飞和阿飞哥，上次青岛晚宴活动，加上阿飞哥给的建议，青岛这边才开始自己攒线下。

上次阿飞回答了大家的多个困惑，甚至是困扰自己几个月的问题被阿飞几句话讲清楚。 这次由欧明宇发起，他讲了怎么找词、怎么弄外链，另外几位青岛的朋友也都聊了自己的经验，收获颇多。

记三个我回去就想试的点： 1、找外链不用只盯玩法一样的竞品。做游戏站的话，别的游戏站也能翻，Semrush 反向链接进去筛活跃和新增，能挖出一批渠道。 2、词根丢进 Google Trends，看相关查询里在涨的那些，根据词根往下找。 3、两个词意思差不多但词汇顺序不一样，前后颠倒各查一遍，搜索量和趋势可能差挺远，当然也可能差不多。

顺便说下，我这种刚入门的，来这种局能看见别人怎么操作，先点哪一步、先看哪一栏、跳过什么。另外就是能当面问傻问题，有时候觉得群里打字问不出口。希望青岛的线下局能一直办下去，下次接着去。
