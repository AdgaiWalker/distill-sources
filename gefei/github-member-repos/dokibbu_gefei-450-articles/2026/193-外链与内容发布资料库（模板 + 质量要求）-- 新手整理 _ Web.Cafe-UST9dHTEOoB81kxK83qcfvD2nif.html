做第一个站尝试去发外链的时候，发现需要的资料五花八门，每每要当场整理准备，特整理一个基本规范，方便下一个站的工作需要。

配套 doc 54 §3(上线提交)/§4(运营外链·内容)。所有对外发布(外链投放、文章投稿、社区发帖)的现成模板 + 硬质量门槛,开新站填空即用。 通用红线(全渠道适用): ①如实(是自己的产品就说是,不刷票/不假评/不买假流量)②相关(不相关的站/社区不投)③分散(描述改写轮换、来源多样、增速平缓,避 footprint)④价值优先(社区先给价值,链接次要)。

1.2 目录/聚合站提交(填空即用)

从素材包取:产品名 / Tagline / 短描述(轮换版)/ 分类 / Logo / 截图 / 官网 URL / 邮箱。 提交 checklist(每站过): □ 分类对准该站体系 □ 描述用当次轮换版(非全站同一句)□ URL 无 UTM 垃圾参数 □ Logo/截图清晰 □ 一站只提交一次(别刷)。 别投: 明显链接农场/PBN 目录、要求互链/付费保证排名的、与主题完全无关的(footprint + 无收益 + 有风险)。

1.3 Product Hunt 发布包


代码块
JavaScript
Name: 【产品名】
Tagline(≤60 字符): 【动词开头的一句话卖点】
Topics: 【3–5 个相关分类】
Gallery: 【首图 = OG 风格封面;后续 = 真实界面截图/GIF】
Links: 【官网(不带追踪参数)】

—— Maker 首条评论(发布即置顶,最重要)——
Hey PH 👋 I built 【产品名】 because 【你遇到的真实痛点/为什么做】.
It lets you 【核心功能一句话】—— 【和现有方案的差异点】.
Free to try, no signup needed. 【一句真实的限制/坦诚,不吹满】.
Happy to answer anything and take feedback. 🙏

质量要求: 首条 maker 评论必须是 真实故事 (为什么做),不是营销话术;全程亲自回复每条评论;禁刷票/买 upvote。

It'd be original, ~1200–1500 words, with 【真实数据/案例】, and no more than 1–2 contextual links (only where genuinely useful).

Thanks,
【真名】 · 【官网】

Your roundup "【页面标题】" is a great resource. I built 【产品名】, a 【一句定位】 —— it 【和榜单里其它工具的差异/补充】, and it's free to try.

If it fits, it might be a useful addition for your readers: 【URL】.
Either way, thanks for maintaining that page.

【真名】

质量要求: ①每封 ≥1 句针对对方内容的 具体个性化 (禁群发无脑模板)②只投主题相关的站 ③guest post 承诺的原创/数据要真兑现 ④跟进 1 次即止,不纠缠。

1.7 first-seen 抄链流程(找编辑链来源)

1.
选 1–2 个同生态位、DR 不高但排名好的赢家站。
2.
用 Ahrefs 拉其 backlinks,按 first_seen 升序 看它冷启动阶段拿的链。
3.
过滤掉 scraper/农场噪声(第一页常 50–70% 是垃圾),留真编辑链/榜单/投稿位。
4.
对每个可复现的来源,用 §1.6 模板去争取。


2 · 内容/文章发布

2.1 内容质量红线（所有文章硬门槛,逐条卡)

•
原创 :不是 AI 通稿复读;至少 1 个竞品/AI 稿里没有的独到点(你的实测/数据/观点/具体案例)。
•
真实数据 :引用的数字带官方或 2+ 带日期来源;禁凭记忆填数 + 编来源。
•
无 AI 味 :具体名词/数字/例子,删"在当今数字时代""赋能""无缝"这类空话。
•
E-E-A-T :真实作者署名 + 1 句 credential;第一人称经验/实测优先。
•
结构可扫读 :开头 TL;DR/要点;H2/H3 分节;段落 ≤4 行;关键结论加粗。
•
关键词自然 :标题含主词;正文主词密度 1–2%,不堆砌。
•
外链 :每篇 ≥1 条对读者有用的权威外链(guest post 另含 1–2 条 contextual 指向自己工具,只在真有用处放)。
•
配图 :≥1 张,原创或授权,alt 齐全。
•
长度 :guest post 1000–1500+;站内核心页 1200+;工具页 800+;程序化规格页 600+。

2.2 站内工具页 / 核心页 结构模板


代码块
JavaScript
H3: 【长尾词2】
H2: FAQ
- 【how to X?】: 真实回答(可含长尾)
- 【is X free?】/【X vs Y?】: 真实回答
[底部]: ≥1 条贴题权威外链;相关内页内链。

卡点: 字数达标(工具页 800+ / 核心页 1200+)· 参数化内容带真实数字非模板复读 · 主词 H1+≥1 H2 · 变体不 301 合并。

2.3 Guest post（换编辑链的投稿文)结构模板


代码块
JavaScript
标题: 【对 host 读者有价值的选题,非软广标题】
开头: TL;DR + 为什么这个话题对读者重要
正文: H2/H3 分节;≥1 个你的实测/数据/案例(独到点);可操作
你的工具植入: 全文 1–2 处,只在"这里用某工具能省事"的自然语境;禁通篇导流
结尾: 可执行的 takeaway;作者 bio(1 句 + 官网链)

质量要求: 对 host 读者 真有用 是第一位(host 编辑只认这个);链接是副产品不是目的;承诺的原创/字数/数据兑现。

2.4 对比 / alternative 页模板


代码块
JavaScript
H1: 【X】 vs 【Y】 (或 Best 【X】 Tools / 【竞品】 Alternatives)
intro: 谁该看这篇 + 结论先行(一句话推荐)
对比表: 【维度:功能/价格/免登录/速度/…】× 【各工具】,数据真实、可核
每个工具一节: 客观优缺点(包括你自己的,别只夸自己)
结论: 分场景推荐(诚实,建立信任)

红线: 对比数据必须真实可核(编数/贬低对手会反噬信任 + 可能被投诉);把自己也客观评。

2.5 发布前自检 checklist（每篇过)

□ 原创、有 ≥1 独到点 □ 数字有真实来源 □ 无 AI 味空话 □ 作者署名 + credential □ TL;DR + H2/H3 可扫读 □ 主词自然、密度 1–2% □ ≥1 权威外链(guest 另含 ≤2 自链) □ 配图 + alt □ 长度达标 □ 词形落位三查过(对站内内容)


3 · 发布节奏与记录

•
外链增速 :新站分散、平缓,别单日/单周暴增(避外链增速异常)。
•
记录 :建一张表登记每次投放(渠道 / URL / 链接性质 dofollow?/ 提交日 / 是否收录 / 引荐流量),便于复盘哪类来源真带权威/流量。
•
复盘 :RD 涨但 DA/排名不动 → 说明缺的是相关性+权威,转 §1.6 编辑链;earned 链(§1.3–1.5 触发的自发报道)优先维护关系。
