之前本地的agent有一个问题，就是没法看google trends，虽然有一些开源的爬虫项目，但是很不稳定，比如已经停止维护的pytrends，所以后来做了一个插件，感觉codex好像也有这个功能来着，但是我不用codex。 我把google trends这块优化了一下，能够结构化输出，包括youtube查询，youtube视频信息拉取，youtube博主的视频列表拉取这写都做成了指令，现在我定时跑的一些任务终于可以在找到一些新的需求后，直接自动到google trends验证、拉长尾词了…

但是，这些查询都是基于浏览器已经登录了谷歌账号和youtube来做的适配，没登录的情况没搞，而且我自己用的是mac，所以windows我也不知道能不能跑通。

使用的话，需要谷歌浏览器上装插件，这个插件我也没发布到浏览器的插件市场，没必要，而且自己发现问题立马就能改，自己用足够了，只不过目前还不支持并行调用。

各位大佬需要的话自取吧，不会装的话，问 AI 吧。

对了，用的 rust，应该需要装 rust 环境，也让 ai 教你吧。
