2026年中哥飞深圳线下，参加黑客松拿到三等奖，我学到的10条方法

6月底刚加入哥飞社群，7月就去了深圳线下，第一次参加。

第一天听了一整天分享，从早上10点到晚上10点，屁股都坐疼了。第二天参加黑客松，做了个图片处理的小站，170个作品排22，拿了三等奖，100美金，6号下午4点半就到账了。

做一个复盘总结。

01 黑客松复盘：我怎么做的

前一天完全不知道要做什么题目 ，本来都打算不参加了，就来看看，但看到题目才发现可行，就先干，干了再说，反正也没什么损失，为什么不做呢。

流程是这样的：

1.
找词 。题目出来后，有点懵，我去问gpt看看有什么方向可以做。
2.
拿着一些组合词和需求词，去一个一个查，trends的流量趋势，看kd的难度，月流量要1k，发现没会员，官方很贵，听到一起参加的朋友说可以去淘宝买，报哥飞名字有优惠，巧用gefei.ai找到了群聊记录，买到会员。
3.
最后这个需求是我根据自己遇到的情况确定的，围绕图片圆形裁剪这类需求去找词，看Google Trends、similarweb看流量是否满足要求，换了好几个词和方向。
4.
上站 。用Codex + 模板，搭一个单页面就能交（黑客松要求单HTML）。核心功能要跑通，UI和交互不能太丑。
5.
SEO自评 。用AIDTK这类工具检查关键词密度、Title、Description、Headings是否覆盖核心词。事实上当时并不知道会有这一层检测。
6.
优化迭代 。把AIDTK的结果丢给geifei.ai分析，让它给具体的优化建议，再让Codex改。包括页面怎么写，结构，布局，关键词设计也是让geifei.ai给的，并且让它帮我确认是否可行（可惜不能上传图片或者链接）。
7.
互评准备 。分数由系统自动评分+群友互评两部分组成，自动分看SEO和性能，互评看UI和体验。

几个实际踩过的坑 ：

•
单词数没控住 ：全页单词数少了，SEO自动评分没拿满。如果一开始就知道1200～1800这个区间，分数能再高一档。
•
关键词密度判断 有朋友现场教了我，不然不会用工具检查，或者不会注意到这件事。
•
页面审美 ：第一名审美一流，单HTML能做的事情有限，UI和交互就是差异化点。

这次黑客松最大的体感 ：以前完全不懂关键词密度，也不会判断什么词能做。这次实战做完， 这些方法从"看文章觉得有道理"变成了"我亲手做过一遍" 。这跟光听分享完全是两个层次。

02 线下大会感受：值不值

简单说几个真实感受，给想报名的朋友一个参考。

1. 出海是新的希望，足够坚定才能走下去。

这是我放在第一条的，因为结果的前提是执行，执行的前提是坚信。我若都不信，凭什么能走下去。

2. 黑客松是真上手，听完就忘。

我自己以前很少去线下大活动，但这次收获确实多。 重点是第二天自己上站做了一遍，印象非常深刻 。还有奖金，真有钱。

3. 认识了几个朋友。

一个人做这件事多少有点孤单。线下认识了程序员、设计师、做其他方向的朋友，互相加个微信，平时可以交流。这点比单纯听分享价值还高。

4. 100块奖金看起来不多，但意义不一样。

"我还没出海成功，就从哥飞社群赚到了第一笔美金收入。"170个作品，4点半就到账，速度快得让我有点惊讶——第一次感受到，做出海的人是真有钱，真赚钱。

到底值不值 ：对我来说值。第二天跟着一起上站的朋友也觉得值，他的站拿了二等奖，学费都赚回来了。

好了，下面是这次线下吸收到的方法，一条条整理。

1. 先选池子：鱼多、人少、有增长

出海就像捕鱼，先找鱼多的地方。

好赛道三个标准：需求大、竞争低、趋势向上。三条都满足最好，两条也够用了。

反过来，大家都知道的模型词红海别碰，跟大佬正面硬刚的别碰，没有信息差的领域别碰。要做的是长尾词+组合词、小语种市场、新趋势词、有信息差的领域。

2. 找词：新词怎么找，老词怎么判断

强调一个排序：找词 > 运营 > 开发。

对程序员来说有点反直觉。习惯了拿到需求就写代码，但做出海站，开发是最不重要的一环。词找对了，简陋的页面也能跑起来；词找错了，做得再漂亮没人看。

我们要学会自己找需求，而词就是需求，去看到新词老词背后的需求。

新词源头分三类：

•
游戏新词：游戏资讯网站、讨论社区、游戏主播视频里最早出现
•
AI模型新词：AI科技公司的官网、博客、官方推特
•
AI玩法新词：刷推特能发现

找到新词后，预判组合方式：新词 + 常见组合词 + 版本号 + 多语言。比如一个新模型出来，一定有人搜"模型名+提示词"，这就是词。Google Trends上出现全新的词，不用管热度高不高，先上。

判断老词值不值得做，三个标准：

1.
有没有人能从这个词赚到钱？
2.
排名靠前的网站是否变现了？（看有没有做功能限制、有没有高级付费功能、接了哪个收款渠道）
3.
有没有人长期花钱投这个词的广告？长期花钱的词，一定能赚钱

还可以从Similarweb看流量大小，看网站是否接了Adsense——这些都是变现信号。

找到词之后怎么做？ 24小时内上站。用模版，不要从头开发。做站如同养鱼，有反馈有流量就多做，没有量就放弃。

这条对我触动最大。我之前一直在想"做什么产品"，但哥飞的方法是"先找到有人在搜什么"。顺序反了。

3. 抄作业：怎么找大佬，抄什么

这里说的"抄"，是研究已经跑通的站，看人家怎么做的。

词找站 ：通过大词、新词去搜，排在前面、花钱投广告多的，就是大佬的站——花钱越多的人，赚得越多。

怎么判断一个站是不是在变好？ 四个信号：

•
是否对功能做了限制（免费版阉割了什么）
•
是否付费才能用更高级功能
•
接入了哪个收款渠道
•
从Similarweb看导入到收款渠道的流量大小

找到大佬站之后抄什么？ 五个方向：抄外链、抄内链与SEO结构、抄SEO页面策略、抄交互设计、抄定价页面。

最后一条是我之前没想到的——看一个网站的 核心卖点 ，直接去看它的Pricing页面。

列出来的都是核心卖点，尤其是高级套餐才有的权益；藏着不给普通套餐用的功能，一定是别的用户愿意花更多钱也想要的。

工具方面，Ahrefs看反向链接和相似站点；预算有限用Bing站长工具也能分析对手外链。

以前我觉得"抄"别人有点丢人。后来想想，人家花钱验证过的路径，不去学反而自己瞎摸，那才叫浪费。

4. 落地页：把用户当婴儿

哥飞说，把用户当婴儿去看待，一点点教他们用。

页面内容原则 ：用户要什么就给什么。要功能给功能，要视频给视频，要商品给商品，要游戏给游戏，要信息给信息。介绍文案不能少，得围绕关键词主题写。

转化路径设计 ：注册门槛和内容入口做低，降低心理预期，提供多元入口。把所有入口收拢到生成器。一个页面解决一个问题，不能太贪。价格页给足情绪价值，增加曝光。功能做不完，可以先放一个假排队。

用户行为路径：搜索 → 理解 → 试用 → 付费 → 生成。每一步都要降低门槛，不能让用户在任何一步卡住。把付费或注册转化放在用户痛点和爽点上。

很多人把注册放在第一步，用户还没体验到价值就被拦住了。这个判断很实际，我以前做页面完全没想过这个。

5. On Page SEO：有硬指标

这块有具体数字，黑客松的时候我踩过坑：

•
Title、Description、Headings都要覆盖关键词，关键词在句子里越靠前越好
•
页面单词数量控制在 1200～1800 左右
•
密度排名靠前的单词必须是核心关键词

我当时做的站就是因为全页单词数少了，SEO自动评分没拿满。如果一开始就注意这一点，分数会好看很多。

6. 外链和增长正循环

外链策略 ：质量要看，数量也要看。一个高质量外链打不过很多个一般般的外链。但有个底线——便宜的外链千万不能要，不舍便宜也不偷懒。预算不多时优先提升数量，前提不能用垃圾。

增长飞轮 ：精准流量 → 更高停留时长 → 搜索引擎权重↑ → 排名↑ → 流量↑。这是一个正向循环。流量带来使用行为，使用行为积累权重，权重提升排名，排名带来更多流量。

增长的规律其实就是大数定律加贝叶斯思维：每个站都可能失败，但做得足够多总能碰到跑通的；每个项目持续优化迭代，沉淀SOP，不追求一次成功。

7. 多语言：翻译是基础，本地化才是核心

一个语种一个网站。

关键词要和当地适配——同一个意思，不同语言的搜索词不一样，流量也不同。不能直接把英文站翻译了就上，得看当地用户真正搜的是什么词。不同国家地区的支付方式都不一样。

英语市场竞争最激烈，换一个语言换一个地区，可能就简单很多。有些站就靠一个小语种市场活得挺滋润。

8. 推广和爆款

选题三个方向：产品功能（你能做什么）、行业热点、不限于产品。

爆款三定律：热点借势、价值肉眼可见、私域自有阵地初始传播。让价值在黄金三秒内可见。

流量获取四条路：

1.
造势流量：TikTok为主，社媒引流到独立站
2.
投流验证：Google Ads、Reddit精准投放、社区灰度测试
3.
SEO截流（最稳的方式）：抢品牌词、抢用户搜索词
4.
冷启动技巧：积分制、裂变机制、限时活动

推特实操方法 ：发推前半小时先去互动评论让账号活跃，发完就去加热——互动、评论、点赞、转发、收藏。

善用quote功能，别人发了爆款就去引用分享它的流量。视频内容有加权重。大V互动 + 可复制内容 + 互动加热 = 爆款公式。

这块有些做过，有些还没意识到，方法记下了，马上可以试。

9. 收入估算和赚钱本质

现场给了一个简单的估算方法：

•
靠 广告变现 的站，按千次访问量 5美金 算
•
靠 用户付费 的站，按千次访问量 100美金 算

基于Similarweb数据就能粗算。只是估算，用来判断一个赛道值不值得进，够了。

赚钱的本质是四种价值：帮用户省时间（时间价值）、帮用户赚到钱（赚钱价值）、让用户开心（情绪价值）、信息差套利（信息差价值）。想清楚自己的站主要提供哪种价值，定位更清晰。

10. 定价和心态

涨价是最快多赚钱的方法。合理定价提升客单价，不会降低付费率。很多人不敢涨价怕用户跑了，但价格本身就筛选了用户。

心态上，不要和AI竞争，要学会用AI；成功等于持续执行加上小概率爆发；大佬看起来突然成功，背后其实是长期积累。

心力上，不要想太多，做就是了。


最后说一下我自己的情况：程序员出身，写代码可以，但找词、找需求，判断竞争、做SEO这些事，之前完全是空白。

这次线下最大的收获，是把模糊的想法变成了可执行的步骤： 选池子 → 找词 → 学大佬 → 上站（24h内）→ SEO优化 → 推广 → 看数据 → 迭代或放弃 → 下一个词 。

每个环节都有具体方法，甚至有具体的数字指标。

这次实战让我对"找词+页面设计+On Page SEO"有了体感，不再只是看文章觉得有道理。

接下来就是进入循环了：找词 → 上站 → 推广 → 看数据 → 优化 → 找下一个词。

先做起来。
