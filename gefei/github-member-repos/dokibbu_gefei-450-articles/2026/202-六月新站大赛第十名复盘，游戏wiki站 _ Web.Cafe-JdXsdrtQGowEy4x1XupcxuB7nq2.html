大家好。

我是新词新站比赛的第十名，做的是TBH: Task Bar Hero相关的游戏wiki站

6月3号发现的词，4号上的站成绩是26K UV 760K PV

对于这种热度的词来说这个站肯定是失败了

除了词选对了

总结出现的问题点

1.
没有选择自己去下载游戏解包，而是选择爬前几名的数据导致数据不完整，数据结构也很差.
2.
这个游戏的资源文件非常大，没有提前处理结构，直接引入导致Workers CPU 费用每天要5💲左右，白白亏钱
3.
没有下载游戏实际玩一下，不知道玩家重点需求
4.
多语言但是游戏资料没有跟页面语言保持一致，大量页面不被收录，这应该是主要原因

从时间线开始复盘一下

6月3号

Task Bar Hero这词我是从游戏社区发现的，很多帖子在发这个游戏在线人数突破多少，首发取得什么成绩。 我发现词的时候已经落后四五天，从谷歌趋势看了一下这个词热度飙升，去steam游戏商店看了一下小公司，新游戏，差评如潮，有steam市场交易。 基本可以确定是可以做的，我当时判断依据是 小公司新游戏肯定没有大规模宣传，不会有那种20年老游戏站竞争对手。 差评如潮不是一个坏的信号，不好玩的游戏连差评都没人打。 有steam市场交易，肯定会吸引大量搬砖打金玩家，这个游戏的寿命应该会很长，不是那种通关就没人玩的游戏，很值得上站。

选域名一般游戏站首选关键词应该是游戏名称，这个站首选肯定是“taskbarhero.wiki”，其次是org,net等等，不选com是因为一般游戏com是官网，最最容易有 纠纷。 问题来了， 这些域名都被注册了 现在两个选择 选top，xyz的垃圾域名。 还有一个选择， 经常玩游戏的都知道，一个游戏如果火出圈，被广泛传播以后就会有一个口语化的缩写 比如league of legends大家平时的搜索习惯是lol, Slay the Spire 2搜索习惯是sts2，Task Bar Hero用户搜索习惯肯定是tbh

纠结了一下最后还是选了TBH作为关键词，我感觉这词竞争小一点

6月4号

获取游戏资料。 这里犯了第一个错误，我没有选择自己去下载游戏解包，而是选择爬前几名的数据 。

给没有做过游戏WIKI站的朋友解释一下，游戏资料比如装备信息，游戏角色信息，技能信息这种属于低保密级别的信息 一般都会随着游戏客户端的下载，保存在用户本地电脑 当然它也不会明文显示一般会用一些固定编码格式 为什么我没自己去解包，因为前几天收到了OpenAI发的警告邮件，说我企图绕过安全警告吧啦吧啦吧啦吧啦。 还有就是， MAC电脑下载不了游戏 ，得重新换到另一台WIN电脑上下载还得折腾。

爬到数据之后直接上站

6月7号

TBH出现在谷歌趋势上 TBH wiki等大量长尾词出现。 当天的网站1k+ UV 发外链

第二个错误，为了让页面关键词密度更高添加了大量AI生成的内容 。

6月10号

当天的网站2k+ UV 发外链

第三个错误，新增了多语言但是游戏资料没有跟页面语言保持一致 。 这个时候我还没有意识到，这个游戏本地资源文件是有多语言，我还尝试让ai翻译了一下游戏资源，但是游戏资源是在太多了，没有全部翻译

6月20号

之前的网站每天都会涨一点，今天只有1K多排查了一下问题。 发外链 果然发现，谷歌从之前的收录160多页面，掉到了只有12个，谷歌上的流量只有几百，其他都是Bing来的流量。

6月21号

网站流量又回到2K+ UV，但是80%变成了中文用户，基本没有谷歌流量了。 搜索了一圈发现源头应该是，游戏社区出现了免费的外挂，进来很多打金工作室 这个时候我人已经麻了，改又怕这点流量都没了，不改谷歌又不收录 选择挂上adsterra 先能赚点是点，有预感这个网站要凉了 发外链

6月25号

site网站这个时候谷歌只收录了首页

游戏开发商更新了新版本，查封了外链，大规模封号，游戏大金没有收益中文用户也都退坑了。

GG

最后让codex 修改发现的问题，主要修改了两点

1.
移除AI生成的内容，不再用虚构内容填充页面，如果页面内容太薄就noindex
2.
游戏资料跟页面语言保持一致

截止到今天谷歌现在收录了二三十个页面，但是流量已经挽回不了了。
