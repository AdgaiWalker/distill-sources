做了一个词根到 google trends 的工具

最近在根据词根找词，需要手动复制词到 google trends，然后设置范围、时间，有的时候找乱了，都忘了这个词根自己找过没有。

基于这个需求，做了一个简单的前端项目，用的是 codex 最新出的 build web app 的应用，很方便，效果看着也还行。 https://keyword-research-desk.vercel.app/https://keyword-research-desk.vercel.app/


参考数据是刘波老哥的词根表，从开源中学习，然后反馈开源，希望对大家有帮助。
