GSC 和 GA4 API 权限开通流程

适合场景：服务器脚本、定时任务、数据看板自动拉取 Search Console 和 GA4 数据。

一、创建 Google Cloud 项目并启用 API

1.
打开 Google Cloud Console
2.
创建或选择一个项目。
3.
进入 API 和服务 → 库 。
4.
搜索并启用：
◦
Google Search Console API
◦
Google Analytics Data API
◦
Google Analytics Admin API
◦
Google Search Console API
◦
Google Analytics Data API
◦
Google Analytics Admin API

二、创建服务账号

1.
进入 API 和服务 → 凭据 。
2.
点击 创建凭据 → 服务账号 。
3.
填写服务账号名称。
4.
创建完成后，进入该服务账号详情页。
5.
打开 密钥 → 添加密钥 → 创建新密钥 。
6.
选择 JSON ，下载密钥文件。
7.
把 JSON 文件保存到你的后端项目中，并确保不要提交到 Git 仓库。

服务账号邮箱长这样：


代码块
Plain Text
your-service-account@your-project.iam.gserviceaccount.com

后面给 GSC 和 GA4 授权时，要用这个邮箱。

三、给 Search Console 开权限

1.
打开 Google Search Console
2.
选择要授权的网站资源。
3.
进入 设置 → 用户和权限 。
4.
点击 添加用户 。
5.
输入服务账号邮箱。
6.
权限选择：
◦
只读取数据： 受限
◦
需要提交 sitemap 等操作： 完整
◦
只读取数据： 受限
◦
需要提交 sitemap 等操作： 完整
7.
保存。

如果有多个站点，每个 Search Console 资源都要单独授权。

四、给 GA4 开权限

1.
打开 Google Analytics
2.
进入左下角 管理 。
3.
选择对应账号或 GA4 媒体资源。
4.
打开 访问权限管理 。
5.
点击 + → 添加用户 。
6.
输入服务账号邮箱。
7.
角色选择 查看者 Viewer 。
8.
保存。

Viewer 权限足够通过 API 读取 GA4 报表数据。

五、代码侧需要的权限 scope

只读拉数据一般用这两个：


代码块
Plain Text

代码块
Plain Text

六、常见错误

403 permission denied ：服务账号没有被加入 GSC 或 GA4。

property not found ：GA4 媒体资源没有授权，或 property ID 填错。

no matching site ：Search Console 里没有对应网站资源，或你授权的是 URL 资源但代码查的是 domain 资源。

安全提醒

不要公开这些内容：


代码块
Plain Text

client_secret.json
refresh_token
private_key
