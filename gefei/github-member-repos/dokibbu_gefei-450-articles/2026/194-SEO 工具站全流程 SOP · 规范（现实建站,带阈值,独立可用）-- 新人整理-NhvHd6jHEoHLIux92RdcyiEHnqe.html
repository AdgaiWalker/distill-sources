0 · 铁律

•
TDH 冻结 【哥飞】:新站上线后先别动 Title / Meta Description / H1。现实里新站头几周排名本就波动,Google 在按用户行为(点击率/停留/回退)判要不要持续给量—— 排名未稳前(至少头 1–4 周)TDH 改动 = 0 (游戏压成"7 天出分",现实更长、更渐进)。CTR 低禁改标题、禁提关键词密度。
•
词形落位三查 【实测】:每个目标词形正文中 ≥1 次落位;关键词密度 ≥ 上一版实测值(只增不减);结构化数据字段与可见内容一致。
•
结论门槛 :≥2 条独立证据才下「结论」;单点证据只写「假设」。
•
趋势门槛 :≥5 天连续同向才算趋势;别拿 1–2 天波动改策略。
•
写进文案/汇报的数字与因果,必须有真实数据来源(禁凭记忆填数 + 编来源)。

红线(命中即否): NSFW 暗语簇 · 同源 footprint 垃圾链 · 纯 AdSense 低价值量矿 · 纯内容站 · affiliate 站 · 趋势衰减盘。

口味(必须全满足): 产品型 · 真收费(订阅优先)· 强意图 · SERP 够得着 · 收入估算达标。

外链: 允许获取(目录/付费位/outreach 都行),投入按 ROI 定,非禁区。外链红线仅:NSFW、同源 footprint。

1 · 选品选词

路径 :只走赢家反推(从已验证的赚钱赢家站反查它在吃的词,禁正推拍脑袋)。烧付费查询(Ahrefs 等)前先定预算(来源/种子/预计消耗)再查。

每个候选词过三道量化闸:

① 竞争闸 · KGR 【哥飞】(免费,先筛):KGR = Google intitle:"词" 结果数 ÷ 月搜索量。 <0.25 强推 · 0.25–1.0 一般(需外链)· >1.0 弃。

新站核心词选 KD<30 (≤36 引荐域可及);KD>50 的头词 = 后期 ROI 账,非新站首选。

③ 可做性闸 · SERP 实测 (最硬,别只看 KD):拉核心词 真实 SERP top10 的域名 DR—— top10 有 ≥1 个 DR<30 在排 = 有缝可做 ;top10 全 DR>40、或含厂商官方页/大平台/垂类权威站 = 弃。

数据核实 :关键词工具(尤其 SimilarWeb 类)的 vol/KD 只当上限参考,决赛词用 Ahrefs 复核; 多语言站查目标国、别用 us (否则把非美流量看扁数倍)。

流量与立项估算(公式,套自己的数):

•
可达月 UV ≈ Σ(每词月搜索量 × 可达位次点击率)
•
位次点击率基线 (行业聚合均值,仅供估算;含 AI Overview 的词再打折; 自家站上线后一律以 GSC 实测为准 ):#1 ~30% · #2 ~15% · #3 ~10% · #4 ~7% · #5 ~5% · #6–10 ~2–3% · 第 2 页 ~1% · 21+ <0.5%
•
月收入估 ≈ 可达月 UV × 转化率 × 客单价(转化率/客单用自家或同类实测)
•
立项门槛 :该估值 ≥ 你的开站目标;词群须含 ≥5 个 KD<20 卫星词 【默认】撑早期。

验收: □反推得出 □红线全清 □口味全过 □≥2 证据 □KGR<0.25 □核心词 KD<30 □SERP top10 有 DR<30 缝 □Ahrefs 复核(目标国) □收入估算达标 □≥5 卫星词

2 · 建站

结构:

•
域名 EMD(域名 = 核心词精确匹配)。
•
一词一页:首页做核心词;首页用 H2/H3/FAQ 覆盖 3–6 个 最大长尾【默认】;其余每个长尾词组 = 1 个内页 ;每个内页 ≥1 条 内链回首页; 变体不做 301 合并 。

页面形态(工具站核心竞争力):

•
工具 + 落地页 + 结果 三合一, 0 跳转 到独立工具页(分离式每跳一步漏一批人)。
•
免登录既能体验核心功能。
•
移动端适配; Core Web Vitals(Google 官方阈值) :LCP <2.5s · INP <200ms · CLS <0.1 。

On-Page 硬清单(建站时逐条卡,不是上线后补;来源:多站体检返工提炼):

模板层(一处错全站错):

1.
footer/侧栏列标题用 <div> ,不用 h4/h5(heading 跳级污染每一页)。
2.
canonical 自引用 + OG 三件套 + twitter card + JSON-LD(WebApplication/FAQPage/BreadcrumbList)+ lang + favicon,布局参数化一次做对。
3.
/sitemap.xml 可访问(框架生成的是 index 就 301 过去)。
4.
CSP 第一天就放开 analytics/广告域。

每页硬指标: 5. Title ≤60 字符 、 Description 140–160 字符 ;desc 别直接复用正文首段。注:140–160 是拉丁文字标准,SERP 按像素宽截断,中/日/阿等每字符更宽,别拿拉丁尺子卡;客户端多语言站 runtime title/desc(JS 改 document.title)是另一层,外部工具测的常是这层,分层核实。 6. H1 唯一含主词; ≥1 个 H2 含主词 ;标题层级逐级递进。 7. 正文词数:核心页 1200+、工具页 800+、程序化规格页 600+;参数化内容带 页页不同的真实数字 ,不是模板句复读。 8. 每页 ≥1 条贴题权威外链 (官方标准/大学 extension/行业协会),target=_blank + noopener。 9. 贴题页配 1 张示意图: <img> 带 alt + width/height + lazy;不贴题的页不硬塞。 10. 工具页: 静态 HTML 里必须有可见输入元素 (爬虫/体检不执行 JS;JS 可接管重建,但首帧要有)。 11. 主词整词组密度 1–2%,正文自然带 4–5 词长短语("free X calculator" / "use the X to")。 12. 一词一页,变体不 301 合并。

数据纪律: 13. 数字/价格上线前必须有真实来源,来源句只写真的 (先实搜拿 2+ 带日期来源 → 校准 → 来源句列真实清单+日期;禁凭训练知识填数+编 provenance)。 14. 公式/常数用官方例题做单测锚点,不自造数字。

部署与验证: 15. apex 自定义域走平台 dashboard 流程(同账号自动建记录,勿手工 DNS)。 16. 部署命令用本地二进制直调(全局命令易被本机 hook 改写炸掉)。 17. 部署后验证内容:边缘传播有窗口,apex 读到旧版时先用部署直连 URL 验内容,再等传播。

验收: □EMD □首页覆盖 3–6 长尾 □每长尾词组 1 内页 + 内链回首页 □三合一免登录+免费额度 □CWV(LCP<2.5s/INP<200ms/CLS<0.1) □Title≤60/Desc140–160/H1 精确含词 □on-page 17 条过 □词形落位三查过

3 · 上线

动作:

•
收录:注册 GSC + 提交 Sitemap + URL 检查请求索引;注册 Bing Webmaster + IndexNow 逐页 ping。
•
曝光/首链:提交 Product Hunt / Reddit r/SideProject / Hacker News(Show HN)。
•
部署验证 + 无痕实搜复核(看 top10 成色、AI Overview/PAA);接入 analytics。
•
首收录判定: site:域名 能查到即算(现实通常 1–7 天 ,比游戏慢)。

上线后窗口硬规 【哥飞】:排名未稳前(至少头 1–4 周)只做加法(加内页、搞外链), 存量 TDH 改动 = 0 。

验收: □GSC+Bing+IndexNow □Sitemap □PH/Reddit/HN □部署+实搜复核 □analytics □site: 已收录 □进入窗口、TDH 冻结

4 · 运营

外链(量化目标 + 现实节奏;已去掉游戏的 $ 成本与单条 DA 跳幅):

•
目标引荐域数 = 核心词 KD 查 §1 表(如 KD30 → 凑 ≥36 个引荐域)。
•
顺序:先低价/免费目录、聚合站堆 RD 广度 (来源分散, 新站别单日/单周暴增 ,避 footprint 与外链增速异常)。
•
RD 达标但排名连续 ≥5 天不动 → 改攻高相关的编辑位/行业站/资源页链 (相关性 + 权威 > 数量;单条编辑链的现实价值远高于一堆目录)。
•
earned 链(现实性价比之王): 保持产品可用以承接自发推荐;主动向 Product Hunt / Hacker News / 相关 subreddit / 行业 newsletter 投稿争取真实编辑链。

权威 → GEO/AI 流量(现实说法,非游戏 DA 阈值):

•
真实权威(高质量编辑链 + 被权威站/媒体提及 + 内容质量 + 品牌搜索量)上去后,ChatGPT/Perplexity/Gemini 等更可能在回答里引用你的工具,带来不吃蓝链排名的流量。 现实没有"DA 到 X 就解锁"的硬线 (游戏用 DA≥15/20 只是示意);做法 = 持续攒真实权威 + 让工具/数据可被引用(清晰事实、结构化数据、可复述的结论)。

头词攻坚: 长尾/变体全 #1 后,再集中资源攻高 KD 头词——引荐域达标 + 主题簇内页 + 高相关编辑链一起推,别指望加内页就能顶上去。

单位经济(阈值):

•
成本余额(API/服务器等)可用天数 <14 天 就补【默认】,断供 = 工具挂。
•
每 UV 边际成本 × 日 UV ≤ 日收入 ,否则涨价、降本或加订阅转化。
•
别只算搜索流量:直接/推荐/AI 引用都有量,具体占比以自家 analytics 实测为准(游戏的 UV=搜索×2 / PV=UV×2.5 只是示意,别当通用常数)。

遇事(禁手贱):

•
流量波动: ≥5 天 连续下滑才排查,期间 TDH 改动 = 0。判「CTR 低」先对位次基线(排在 #8 位,点击率本就 ~2–3%,不是异常)。
•
算法更新:冻结存量、只观察;可加内容/链, 禁改 TDH 。内容扎实 / 链干净 / 体验好的站,核心更新多半受益。
•
竞品进场:护城河 = 累积权威 + 全词 #1 + 用户信号;继续加宽(链/内容/earned),不动存量页。

验收: □引荐域达 KD 目标数 □RD 停滞时已转编辑链 □earned 承接就绪 □余额天数≥14 □每 UV 成本≤单 UV 收入 □波动/更新/竞品 0 次动 TDH □按位次基线判 CTR

5 · 终局

•
到顶判定:目标词群 ≥90% 词 #1 且权威增长趋缓、流量进平台期。
•
转维持:停买链;内容 季度 更新一次【默认】;保成本余额;人力砍到最低,站当半自动现金牛。
•
释放资源 + 本 SOP 复制到下一个 niche(护城河是可复制的打法,不是单个站)。

验收: □词群≥90% #1 且增长停 □转维持(停链/季更) □回 §1 开下一个 niche

6 · 执行时用到的工具类型（资源,按自己环境准备）

•
关键词量/难度 + SERP DR:Ahrefs(或 Semrush)
•
全渠道流量核查(补 SEO 工具盲区):SimilarWeb 类
•
竞争度免费预筛:Google intitle: + KGR 计算
•
外链来源:可投稿目录/资源页清单 + 抄同生态位赢家 first-seen 外链
•
建站/部署:静态站生成 + CDN;体检:on-page audit 工具
•
收录:GSC + Bing Webmaster + IndexNow
