哥飞大会 + 第一次参加阿飞线下局的收获

先说说我自己

去年6月，我和伙伴们一起参加了哥飞线下大会+黑客松，还上站拿了小奖。

我学编程出身，做了8年产品经理，G端、B端、C端，国内国外的用户都做过。去年3月开始上站，陆续上了15个站，身边也有一小撮在深圳红山上站的伙伴，从上站到有用户付费的完整路径，都是真实跑通过的。

去年7月底，我进入了人生的一个新阶段，做了很多尝试，有了一些新经历和收获：Web3从业、知识付费、私域、海外内容运营、人生教练……最近，我重新盘点了下个阶段想做什么。

其中一个明确的答案是：上站，继续搞起来。于是我又来参加哥飞大会了。

这次线下虽然没见到老伙伴，但这一场听下来依然受益很多。紧接着第二个周末（就是昨天），我又去参加了阿飞组织的深圳线下局。

让自己持续留在牌桌上——这是这一次我给自己的"道"。

群里每天的小课堂知识量太大，上站占用的时间也很多，复盘不能再拖了，今天必须写完——写完也是为了指导自己后面做事情。

大道至简。对我来说，能对日后有指导意义、最底层、最适配自己的，才是最好的。所以，我准备用 道、法、术、器 四个层次来提炼这次的收获。

框架听着熟悉，但不重要，都是为了吸收的更好和执行。


道

这一年的主线： 先从新词做到万刀，跑通之后，再走老词、做品牌。

法

1.
有一个好看的壳
2.
定好方向——选新词上站
3.
做外链
4.
优化站内、提升转化

术

不管是嘉宾分享，还是哥飞社群里的内容，每天群里的小课堂，"术"层面的东西有一大堆，重点是要 实操 。这一块我会持续搞知识库来沉淀，最终实操做判断的时候，还是要自己踩过坑、复盘过，才能形成属于自己的判断，最终形成自己的术。

基础动作：先上站 → 搞流量 → 搞优化。

以下是这次听下来在"术"层面的具体收获：

① 方向（去哪找新词）

1.
游戏新词：各个游戏资讯网站、游戏讨论社区、游戏主播视频
2.
AI模型新词（不同类型的AI工具）：各个AI科技公司的官网、博客、官方推特
3.
AI玩法新词：推特，以及 Higgsfield 等能够自创玩法的网站
4.
谷歌趋势：全新出现的词，先做了再说
5.
从已定方向的高流量网站找新词：近期有趋势上涨、且同类网站打得过的（SimilarWeb）

② 冷启动策略（核心是让行为数据表现好）

1.
尽量延长用户停留时间：每日打卡送积分、生成速度放慢一点、增加交互效果等等
2.
功能多、做不完的，可以放一个"假排队"，让用户有期待，还能回来看
3.
人均访问页面次数越多越好
4.
免费策略可以带来传播扩散、提升用户行为数据（先把用户搞进来，之后再过滤掉低价值地区的流量）

③ 外链

1.
免费外链的质量判断标准：DR>20；建站年限>半年；流量>1k，且近3个月流量呈上升趋势，有自然搜索关键词
2.
发外链可以用指纹浏览器
3.
权重>20的低流量站（自己的），可以加外链提及自己的优质站，给它提权重
4.
找外链路径：听到最靠谱的方法是把优质导航站的外链全部下载下来，然后一个个去看。大佬说他看了2个月才看完，靠这个积累到一天可以发1000条外链，第二天接着发还不重复）
5.
竞品外链反查：Bing站长后台 | Ahrefs → 反向链接 → 相似组 → 首次看到 | Semrush 抄同行

④ 转化

注册、使用链路通常、付费，腰逐步提高这三步每一步的转化率。 方法就是爆改UI、「以用户体验为主」，把用户当婴儿看。

⑤ 数据观测

1.
自建SQL
2.
轻量化场景用 Plausible 看数据

⑥ 网站差异化

搜目标关键词，把排名前三的竞品交给AI分析各自的定位，输出 how to 差异化。（John 的AI用法很靠谱，值得用在产品分析上。不过产品方向其实可以根据用户的实际使用慢慢调整，进而提高付费，不用着急。）

⑦ 内页

热点能蹭即蹭。
