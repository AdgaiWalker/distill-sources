这次参加哥飞的深圳年中分享会，学到了很多，也很幸运地拿到了黑客松一等奖和 1000 美金奖金。

在这里和大家分享一些自己的收获，希望可以和大家相互学习。


一、去做，比什么都重要

这次交流时，我发现不少人其实都还在“观望”这个领域。大家都会说自己本职工作繁忙，没什么时间尝试。

这次听到了很多实用的方法和技巧，但对我来说，最重要的收获其实只有两个字：

去做。

所有人一开始都在摸索。很多这次分享的嘉宾，可能一年前也和现在的我差不多， 不知道自己做的事情最后能不能获得正反馈，也不知道哪一条路能够真正跑通。

但只有开始做，才有可能获得反馈。

而从另一个角度来看， 几乎所有反馈都是有价值的 。即使一个产品没有赚到钱，你也会对这个需求、渠道或者市场多一层理解。正是这些不断积累的认知，最终决定了我们有没有机会赚到钱。

赚美金比想象中难。因为如果不愿意持续摸索、研究和迭代，确实很难获得结果。

但赚美金可能也比想象中容易。因为大部分人不会真正开始，更少有人能够一直坚持。


二、SOP 是动作，但更重要的是理解动作背后的目标

目前大家比较熟悉的出海产品 SOP，大致是：

1.
找词：找到高需求、低竞争的搜索词
2.
做产品：做出能够满足需求的产品
3.
发外链：通过外链获得 SEO 流量

这套 SOP 本身没有问题。

但我觉得，更重要的是继续往下拆解： 这些动作分别是在完成什么目标？

•
找词的目标，是 找到需求
•
做产品的目标，是 满足需求
•
发外链的目标，是 找到流量

当我们理解了这些动作背后的目标，就不会被某一种固定的方法限制住。

例如，搜索词可以帮助我们找到需求，但 Reddit、Hacker News、竞品评论区同样可以。Vercel、Stripe 上增长比较快的产品，或者竞品新上线的内页，也可能帮助我们发现新的机会。

找词仍然是一种非常有效的方法，但它并不是找到需求的唯一方式。 发外链也是一样。

发外链的本质是获得流量，但获得流量的方法并不只有 SEO。群里有人分享，他在 TikTok 发布的 AI 视频爆了，随后为自己的 AI 视频生成网站带来了大量用户。这同样是在解决流量问题。

对于新手来说，先按照成熟的 SOP 上站，已经能够减少很多无效探索。

但理解每一步背后的目标，可以帮助我们判断：为什么要做这个动作？这个动作有没有变形？有没有其他更适合自己的方法？

这样才更容易真正获得结果。


三、我如何拿到这次黑客松一等奖

这次我做的产品在现场排名第四，获得了一等奖。

下面也来分享一下，我是怎么找到这个方向，并把产品实现出来的。


1. 找词

在确定词根是 image 后，我使用 Similarweb 的 Keyword 功能，筛选了包含 image 的搜索词。

接着按照活动要求，筛选出月搜索量大于 1000 的词，再按照 KD 从低到高逐个查看。这个方法也是飞哥之前分享过的。

通过这种方式，我找到了几个符合条件的词，最后选择了：

image to text prompt generator

选择这个词，主要有几个原因。

•
首先，通过哥飞的工具计算后，它的 KD 是几个候选词中最低的。
•
其次，这是一个需要使用 AI 才能较好完成的任务，用户价值相对比较高。
•
另外，它最终生成的是文字，而不是图片或者视频，因此推理成本更低，返回速度也更快。


2. 实现产品

我的本职工作是产品经理，不会真正写代码。

之前我也用 AI 做过一些网站，这次最开始仍然使用 Codex 开发。做到一半时，Codex 的 5 小时额度用完了，于是我临时开了一个 Cursor 会员，最后使用 Cursor 的 Composer 2.5 完成了产品。

Composer 2.5 的效果比我预期中好，甚至在这次开发过程中，它出现返工的次数比 Codex 还要少。

这也让我更加明显地感受到， AI 编程工具的进步非常快。

对于这类复杂度不算特别高的产品，现在很多 AI 工具都已经能够完成大部分实现工作。随着产品实现门槛不断降低，我们可能需要把更多精力放在另外两件事情上：

找到真实需求，以及找到稳定流量。


3. UI 是怎么做的

从功能上来说，我不认为这个产品有特别明显的创新。

它最后能够拿到第四名，我觉得一个比较重要的原因，是 产品的 UI 看起来还不错，整体完成度也比较高。


在颁奖时，我也提到了自己的 UI 设计方法。诀窍其实非常简单：

抄。

这里的“抄”并不是完整复制另一个网站，而是主动寻找自己喜欢的设计参考。

当你看到一个喜欢的网站时，可以把截图和链接发给 AI，让它分析这个网站的字体、排版、留白、配色和组件风格，再让它将这些设计语言应用到自己的产品中。

我正是通过这种方式，快速把产品的 UI 从“功能可用”，提升到了“看起来也比较像一个完整产品”的状态。

对于不会设计的人来说，这是一种 成本很低、效果也比较稳定的方法 。


4. 黑客松中的一些小策略

因为黑客松需要其他参赛者直接体验并评价产品，所以我一开始没有设置太多使用限制。

产品不需要登录，也可以无限使用。

之所以敢这样做，是因为这个产品最终输出的是文字，单次生成成本比较低。而且与图片、视频生成相比，文字返回速度明显更快，对网络环境的要求也更低。

这在黑客松互评中其实比较占优势。

一些其他参赛者的产品可能功能更复杂，完成度也很高。 但图片或者视频生成往往需要等待更长时间。如果现场网络不稳定，用户等待一段时间后仍然没有看到结果，很容易把问题归因到产品本身，进而影响评分。

所以在黑客松这种场景下， 不只是产品能力重要，体验链路是否足够短、结果能否快速呈现，同样非常重要。


5、这个网站接下来的计划

黑客松结束后，我还在持续迭代网站，已经增加了登录功能，支付流程也已经跑通。

接下来，我会继续优化产品，希望它能够成为我第一个真正开单的网站。

我相信只要我持续去做，这一天就不会远。
