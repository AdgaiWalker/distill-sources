之前群友问有没有必要做出差异化，我的回答是没必要做功能上的差异化，因为同一个关键词背后的需求都是差不多的。

但注意，你不能为了差异化，就把本来应该要有的功能也不去做了。

差异化要从 UI 和 UX 上去找。即使是能拿到搜索排名靠前的网站，做法也各有不同，但殊途同归，目的都是最高转化效率。

有群友花一个月全面升级 UI 和 UX，从廉价感做到高级感，之前每月只有一笔付费，之后 10 天来了 4 单。

他自己补了一句提醒：改动整站文案必然导致一段时间自然流量动荡，大家不要学我，尽量在站上线之前就规划好定位。
