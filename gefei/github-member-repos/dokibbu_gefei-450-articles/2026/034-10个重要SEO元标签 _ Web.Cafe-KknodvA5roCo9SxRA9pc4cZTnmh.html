一、Title 页面标题

四点建议：

•
为每个页面提供一个独特的标题，简洁准确地描述页面的内容；
•
标题长度保持在50-60个字符以内（以免在搜索引擎结果页面中被截断）；
•
将重要关键词放在首位，但要自然，就好像你首先为访客编写标题一样；
•
在标题中使用您的品牌名称，即使最终不会显示在搜索引擎结果页面上，对搜索引擎仍会产生影响。

二、Description 页面描述

•
为每个页面提供一个独特的元描述，清晰地反映页面所传达的价值；
•
谷歌的摘要通常最多约为150-160个字符（包括空格）；
•
包括您最重要的关键词，这样它们在实际的搜索引擎结果页面上就会被突出显示，但要小心避免关键词堆砌，不要让您的描述只是您正在针对的关键词的组合；
•
可选择地，使用引人注目的号召行动，您提供的独特主张，或者关于期望的额外提示 - 如“学习”，“购买”等构建。

三、Heading 标题标签（H1到H6）

•
确保标题与它们描述的文本段相关。搜索引擎虽然不会将其作为排名因素，但仍会考虑它们；
•
请始终让标题反映其所覆盖的文本的情感。避免使用简单的顺序标题“第一章...第二章...第三章...”的标题；
•
不要过度使用标签和其中的关键词。保持对用户的可读性。

五、链接的 Nofollow 属性

通常以下场景需要设置 nofollow ：

•
任何可能被视为“不受信任内容”的资源链接；
•
任何付费或赞助链接（你不希望谷歌发现你在出售“选票”）；
•
评论或其他类型的用户生成内容中的链接可能会被滥用，而这是您无法控制的。

HTML <a> 标签（超链接）中的 rel 属性有几个属性值（noopener、noreferrer、nofollow）

•
1.rel="noopener" (安全性与性能) 主要用途：防范钓鱼攻击（安全性）
•
2.rel="noreferrer" (隐私) 使用场景：当你不希望目标网站知道是你把流量导给他们的时候。
•
3.rel="nofollow" (SEO - 搜索引擎优化)

使用场景：

•
1.付费链接/广告： 防止被搜索引擎判定为操纵排名的“黑帽 SEO”。
•
1.用户生成内容（UGC）： 如博客评论区、论坛帖子。防止垃圾评论者为了留外链刷排名而滥发评论。
•
3.不信任的网站： 你必须引用某个网站，但不想给它背书。
•
4.不想分散权重

•

七、canonical 标签

它是是用来告诉搜索引擎，当前网页的规范网址是哪个的 这里特别注意的是，你的真实网址是什么，就应该返回什么，而不是整个网站所有页面都统一返回首页的地址，这里写错了后果会很严重。

九、Social Media 社媒元标签
