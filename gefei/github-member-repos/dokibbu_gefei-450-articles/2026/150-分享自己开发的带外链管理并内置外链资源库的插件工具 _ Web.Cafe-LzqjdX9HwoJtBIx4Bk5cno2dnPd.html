发外链是做 SEO 最痛苦的事之一。要想发出"看起来像真人写的、对页面内容真的有理解的"评论，传统做法是手动一条一条来——又慢又差。

Backlink Helper 是一款 Chrome 浏览器插件，直接在浏览器右侧侧边栏打开**，**用来帮助你管理外链资源、生成评论内容，并把名称、邮箱、网站地址等信息快速填入网页表单。

你只需要：

1.
把你的网站、邮箱、文本一次性配置好（支持多站、JSON 导入导出）
2.
接入你自己的 AI Key（ 支持 Gemini / OpenRouter / 硅基流动 等主流通道，你想用哪家用哪家、想用什么模型用什么模型）
3.
在任何一个支持评论的网页上，点击"内容评论 / 带链接评论"，插件就会自动读取页面内容，生成原语言评论 一键复制粘贴

关键是它 支持你自带 Key ——意味着你的成本就是模型 API 的成本，不需要再多付一份订阅费。

适用版本：v1.1.1 欢迎大家试用插件 哥飞群友免费使用50条内置外链库

安装插件

Chrome 不支持直接安装 zip 文件，需要先解压。

1.
右键 backlink-helper-1.1.0.zip ，选择“全部解压”或“解压到当前文件夹”。
2.
解压后进入文件夹，确认里面能看到 manifest.json 文件。
3.
打开 Chrome，在地址栏输入： chrome://extensions/ 打开插件管理面板
4.
打开页面右上角的“开发者模式”。
5.
点击加载未打包的扩展程序（ 如果没有看到这个按钮，根据提示先开启开发者模式 ）。


6.
选择刚才解压出来、包含 manifest.json 的文件夹。
7.
页面出现 Backlink Helper 后，说明安装成功。


建议安装后点击浏览器右上角的拼图图标，把 Backlink Helper 固定到工具栏，后续打开更方便。


Edge 浏览器安装方式类似，地址栏输入：

edge://extensions/

第一次打开

1.
打开任意普通网页，不要在 chrome://extensions/ 这类浏览器内部页面测试。
2.
点击浏览器右上角的 Backlink Helper 图标。
3.
插件会以侧边栏形式打开。
4.

如果点击插件图标没有反应，可以刷新当前网页，或重新加载插件后再试。

AI 模型管理

如果要使用“内容评论”和“带链接评论”，需要先配置 AI。

侧边栏设置-tab切到模型连接

1.
点击插件右上角齿轮按钮，打开设置页。
2.
切换到“模型连接”。
3.
在“选择 API 提供商”中选择服务商，例如“硅基流动”。
4.
在“API 密钥”中填入你的 API Key。
5.
在“模型选择”里选择模型。
6.
如果下拉列表里没有你要用的模型：
◦
在下方输入模型名称
◦
点击“添加模型”
◦
新模型会出现在下拉列表中
7.
点击“API连接”测试是否可用。
8.
测试成功后，点击页面底部“保存设置”。


硅基流动常用预设模型：

Qwen/Qwen2.5-72B-Instruct

如果使用自定义模型名称，请确保它和你的 API 账号中可用的模型名称完全一致，包括大小写、斜杠和版本号。

授权与额度

插件顶部会显示“授权与额度”。


50条高质量外链这是免费额度限制。输入有效授权码并验证成功后，可以查看和使用内置的226条完整外链列表。


未授权用户：

•
可以使用前 50 条外链资源 超出后会提示输入授权码 找俊哥申请授权码 一人一码，永久权益
•
仍可使用基础复制、手动填写等功能

已授权用户：

•
解锁全部外链资源 不再受免费额度限制

授权步骤：

1.
在插件顶部“输入授权码”框中粘贴授权码。
2.
点击“验证授权码”。
3.
看到“已授权”后即可使用全部外链。

注意：

•
普通授权码通常会绑定当前浏览器设备，请不要随意分享给别人。
•
如果提示“授权码已绑定其他设备”，说明该授权码已经在另一台设备上使用过。
•
如果提示“授权码不存在”或“授权失败”，请检查是否复制了多余空格，或联系发码方。

1.

2.

3.

4.

提交外链

“链接格式”决定生成带链接评论时链接长什么样。

HTML：适合 WordPress、部分博客评论区

Markdown：适合 GitHub、技术社区、Markdown 编辑器

BBCode：适合部分论坛

纯URL：适合不支持富文本链接的网站

如果不确定选哪个，先选“纯URL”或默认的 “BBCode”，填入后人工检查页面是否显示正常。

**内容评论 **

会读取当前网页标题和正文，然后调用 AI 生成一段自然评论。

使用步骤：

打开目标文章或页面。

点击评论区输入框，让页面准备好接收文字。

点击插件里的“内容评论”。

等待 AI 生成。

插件会尝试把评论填入当前页面输入框。


带链接评论

“带链接评论”会根据当前页面内容生成评论，并自然附上你当前选择的网站链接。

使用步骤：

在“评论信息”里选好要推广的网站。

选择合适的链接格式。

打开目标文章或评论页面。

点击评论区输入框。

点击“带链接评论”。

生成后检查内容是否自然、链接是否正确，再手动提交。

建议发布前一定人工检查，不要直接批量提交未经确认的 AI 评论。
