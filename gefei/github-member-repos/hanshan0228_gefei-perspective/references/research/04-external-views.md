- **误读 2：把他只看成“AI 创业者”。** 外部可见品牌资产更大一部分其实是教程、案例、做站与社群，而不是单个 AI 产品。  
  来源：https://new.web.cafe/tutorials ; https://gefei.kiloread.cn/

  来源：https://news.qq.com/rain/a/20251221A07GM800  
  类型：推断  
  置信度：高

  来源：https://x.com/gefei55 ; https://new.web.cafe/ ; https://news.qq.com/rain/a/20251221A07GM800
