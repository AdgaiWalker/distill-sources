大家好，我是哥飞。

为了让不懂代码的你也能做游戏站，我做了一个游戏站引擎。

注意，不是“游戏引擎”，是“游戏站引擎”。

群里很多朋友想做游戏站，词也找到了，最后卡在同一个地方：不会写代码。

这两年我一直说，代码可以交给 AI 写。但真走下去就会发现，AI 写出来一堆代码，接下来怎么部署、怎么绑域名、改坏了怎么回退、做第二个站是不是又从头来一遍，对不懂代码的人来说，每一步都是门槛。

所以我做了一个游戏站引擎，叫 GeFeiSites 。

它解决两件事：

• 你不用碰代码。网站长什么样、有哪些页面、每一句文案，都由 AI 通过引擎来写。你要做的是跟 AI 说话，在后台点按钮。

• 一次部署，上线多个网站。引擎部署在你自己的 Cloudflare 账号里，免费套餐就够。部署一次之后，再做新站，就是在引擎后台填一个域名，不用再部署第二遍。

它是怎么做到的？

引擎通过 MCP 把建站、写页面、发布、体检、绑域名、推送搜索引擎这些能力开放给 AI。

你在哥飞 SEO Agent、Claude 或者 Claude Code 里说一句“帮我把这个游戏站做出来”，AI 就去引擎里干活，做完给你一个预览链接，你看满意了再发布。

做过游戏站的朋友都知道，游戏新词一波接一波，看中一个就要尽快上一个站。如果每个站都是一套单独的代码，每次都单独部署，很花时间，而且上站多了之后，你有十个站就要维护十分代码，很麻烦。

GeFeiSites 引擎的做法是：整个引擎是你 Cloudflare 账号里的一个 Worker，所有网站都跑在它上面。访客打开哪个域名，引擎就拿出哪个站的内容。每个站有自己的域名、自己的界面、自己的页面和数据，互不干扰。

在后台新建一个站，只要填域名和站名，之后就交给 AI 帮你做。甚至于这一步都可以你跟 AI 说，让 AI 帮你做。

给大家看下引擎后台，左边的导航会列出你所有的站，绿点是已经上线的。

示意图：一个引擎里的四个站（示例域名），三个已上线，一个还是草稿

这也意味着，你在一个站上省下的功夫，全用到下一个站上：统计、通知、推送、绑域名这些设置只配一次；引擎里还有一本“经验之书”，AI 在任意一个网站上学到的东西都会记下来，你后面上新站，就可以复用这些老经验。

但UI界面是不共享的，引擎并没有内置任何 UI，每一个站的 UI 都需要 AI 去根据网站主题来编写。

这是吸取了一些教训的，如果引擎内置了 UI，很多人就会懒得去改 UI，导致同一个引擎做出来的网站几乎都长得差不多。

引擎不是一次做好的。第一版放给群友用之后，群友一直在给我反馈。我就一直让 Claude 去更新迭代引擎。

第一步：先让 AI 能干活

引擎的核心是给 AI 用的一套工具：建站、写模板和样式、写页面、录游戏、体检、发布、回滚、看数据。

AI 连上来以后，会先读我写的创作指南。指南里是这几年群里做游戏站的做法：首屏就是游戏、一个页面只打一个词、第一版从简先上线。

接 AI 这一步我尽量做成了一键。

用哥飞 SEO Agent 的，在引擎后台点“一键连接”，跳到 SEO Agent 那边点“确认”，不用复制任何令牌。

（不过就在写这篇文章时，群友反馈，这个功能好像被AI改坏了，我得赶紧写好文章再去让 AI 把功能改回来）

用 Claude、Claude Code、Cursor 的，后台生成一个令牌，页面上直接给出要粘的那一串。

示意图：上手引导一共 9 步，做完一步自动打勾

第二步：连 Cloudflare，从「教程」改成「一个按钮」

引擎要替你绑域名，得有一个你的 Cloudflare API 令牌。一开始我写了五步教程：选模板、加权限、选账户……结果群友说跟着教程也不会，卡在权限那三层下拉框里。

后来发现 Cloudflare 支持把权限预先填在建令牌的链接里。现在这一步就是一个按钮：点开以后权限都勾好了，你只要点「继续」「创建」，把令牌复制回来。

示意图：连 Cloudflare 只剩三下

第三步：域名自己绑好

绑域名是新手最容易放弃的一步。

现在的流程是：你去 query.domains 查哪些域名还能注册、在哪家买最便宜，买好以后在引擎里填上域名。

域名不在你的 Cloudflare 账号里，引擎自己加进去，告诉你到注册商那里把 DNS 服务器改成哪两个。

这一块改了好几轮：

• 两个 DNS 服务器单独列出来，各带一个复制按钮。哪个已经生效、哪个还没有，多出来的哪个要删掉，都标在上面。只改对一个，是最常见的卡点。

• 页面开着就每 30 秒自动查一次，点“现在检查”也不会整页刷新。

• 生效以后，引擎自动把主域名和 www 都绑上，www 跳到主域名，http 跳到 https。群友反馈过 http 打不开、www 报 400，现在都由引擎处理。

• 绑好了还不算完，你的浏览器会当场去打开一次网站。证书还在签发就告诉你在等什么，能打开了才写「域名可以用了」。

示意图：还差一步的时候，哪个生效了、哪个要删，一眼看到

示意图：绑好以后，逐项打勾

第四步：每个站一份上线清单，功能就放在清单里

每个站的页面最上面是一份上线清单：绑域名、把站做出来、图标和分享图、发布、统计、推送搜索引擎、Google Search Console、Bing、联系邮箱、ChatGPT 推荐流量、让 SEO Agent 检查一遍。引擎看得到的自动打勾，发生在别处的你做完自己勾。

一开始清单只是告诉你“去下面某一栏”，群友说要翻好长一段去找。现在功能就放在清单那一项里，展开就能操作。

每一件要 AI 做的事，引擎都准备好了提示词，里面写好了引擎地址和这个站的域名，AI 不会弄错站。

点“在 SEO Agent 里打开”，提示词直接放进输入框；用别的 AI 就点复制。图标和分享图也是 AI 做：它写 SVG，引擎转成各平台要的 PNG。

示意图：要 AI 做的事，提示词都写好了

还有一个我很喜欢的设计，是哥飞特意要求 Claude 做出来的。

SEO Agent 检查出来的问题，记进引擎里这个站的“待办”；Claude Code 读到待办去修改；改完 SEO Agent 再来复查，确认真的改好了。两个 AI 之间不用站长复制来复制去传话，引擎就是中间人，太省事了。

第五步：上线当天就去拿 ChatGPT 流量

在哥飞社群里，GEO 就是 ChatGPT 推荐过来的流量，是现在新站最快的流量。国庆期间，我零外链的测试站，第 4 天就来了 ChatGPT 流量。

清单里这一项按我平时的做法拆成四步，每一步的提示词都按你的站填好了：让 ChatGPT 打开你的网站；问它海外玩家会怎么提问；在新对话里一个个问，记下它引用了哪些网页；把结果交给 AI，补上首页缺的回答。引擎发布时还会自动用 IndexNow 推送给 Bing 等搜索引擎，这对更快拿到 ChatGPT 流量也有帮助。

第六步：自己做小游戏，后端引擎包了

除了嵌入别人的游戏，也可以让 AI 自己写小游戏。

游戏要的后端，引擎都统一提供：题库、每日题这类内容的存储，排行榜、存档、选择统计这些玩家数据。

最近又加了做裂变玩法用的“访客记录”。比如朋友测验：你出题、生成一个链接发给朋友，朋友答完看自己的分数，再生成自己的链接发出去。

答案只放在服务器上，由服务器判分，网页上偷看不到。

我的原则是：引擎只提供通用的能力，具体是测验还是送花、留言墙，由 AI 在站里按需写。

第七步：引擎自己提醒你升级

有群友问，引擎更新了是不是要重新 Fork？不用。

有新版本时，后台最上面会告诉你落后了几次、每次更新了什么，并给出你自己那份仓库的链接。

点「Sync fork」和「Update branch」，Cloudflare 会自动重新部署。引擎在后台替你盯着，部署好了提醒你刷新。你的网站和数据都不受影响。

示意图：有新版本时的提示

还有一堆小细节

有群友说，后台应该做成左侧导航，用好大屏幕，于是就改成了现在这样。有人说点了按钮没动静，现在所有按钮点下去都会转圈，处理完在底部弹一条提示，页面不再整个刷新。有人说“重新检查”按钮太显眼，就改成了小号灰字。

这些都不是什么大功能，但一个工具好不好用，往往就差在这些地方。

不懂代码，也不用怕弄坏

不碰代码的另一面是：出了问题，你也不会去翻代码。所以引擎自己要把好关。

• 删东西先进回收站。删网站、删页面、删游戏、删玩家数据，都先放进回收站，30 天内能原样恢复。删网站还要你手动输一遍域名确认。AI 能把东西放进回收站，但彻底删除只有你在后台能做。

• 每次发布都留版本。发布前自动体检，有错误发不出去；发布后不满意，一键回滚到之前任何一个版本。

• 防刷是引擎统一做的。访客提交的排行榜、评论、记录，按网络限额，换个浏览器也绕不过去；重复的内容、恶意举报都拦得住。哪个站被刷得厉害，在网站页把 Cloudflare 的人机验证打开就行。

• 有事发到你的群里。嵌入的游戏失效了、有新评论、每周一的周报，都可以发到飞书、钉钉、企业微信、Telegram 或 Discord。

• 所有东西都在你自己的账号里。引擎、网站、数据、各种令牌，都在你自己的 Cloudflare 账号里。Web.Cafe 这边只知道你连了哪个引擎、有哪些站，不存你的任何密钥。

怎么开始

GeFeiSites 是给社群会员的付费源码，在 new.web.cafe 的会员权益页购买，会员价 99 元，可以用咖啡豆支付。内测期名额按批放出。

买完会自动跳到“我的网站”页，那里有一步步的指引，全程在网页上点：

1. 绑定你的 GitHub 账号，点“申请授权”，接受 GitHub 邮件里的邀请。

2. 把仓库 Fork 到你自己的 GitHub。

3. 在 Cloudflare 里导入这个仓库部署，部署命令填一行，其余不动，一般两三分钟。

4. 打开引擎后台，设置管理员密码，连接 Web.Cafe。

之后的事，引擎后台的上手引导会接着带你做。花钱的地方只有域名，Cloudflare 免费套餐就够跑引擎和你所有的站。

还是那句话：做站拼的是速度。

以前从找到词到上线，不懂代码的朋友要花好几天去弄技术的东西，现在这些交给引擎和 AI，你把时间花在找词、看数据、想怎么让玩家留下来上。

最快半小时就可以上线一个新游戏网站。
