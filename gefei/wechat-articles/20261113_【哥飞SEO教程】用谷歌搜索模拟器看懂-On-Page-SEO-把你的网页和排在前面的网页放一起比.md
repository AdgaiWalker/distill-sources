把你的网页和排在前面的网页放进模拟器比一比

大家好，我是哥飞。

很多朋友写网页时，不太清楚搜索引擎拿到一个网页以后，是怎么判断它跟某个关键词有没有关系、该排在前面还是后面的。网页上线了搜不到自己，也不知道该从哪里改起。

为了帮大家加深对 On Page SEO 的理解，我做了一个辅助学习 SEO 的工具，叫谷歌搜索模拟器：

https://new.web.cafe/search-simulator/

它分成两部分。第一部分是爬虫建档，你把任意网页填进去，可以一步一步看爬虫是怎么抓取网页、提取信息、分词处理，再建立正向索引和倒排索引的。第二部分是模拟搜索，输入你想做的关键词，看你的网页能不能匹配命中这个词。

还可以把某个关键词排名靠前的网页放进去，再把自己的网页也放进去，看看自己的网页跟排名靠前的网页差在哪里。

下面我用一个真实的例子，带大家走一遍。

## 第一步：把网址放进去，抓取并建立索引

11 月 13 日，我在谷歌（美国、英文）搜了 image to 3d model ai，从排在前面的结果里拿了 image-to-3d.ai、meshy.ai、3daistudio.com 三个网站的首页。另外再放一个完全不相关的网页，维基百科的面包词条，用来对比。

把这四个网址粘贴进去，点“抓取并建立索引”，模拟器就会把四个网页的 HTML 抓回来。

谷歌搜索模拟器：粘贴四个网址后点“抓取并建立索引”

搜索引擎的爬虫把每一个网页都叫做一个文档。我贴了四个网址进去，这里就有四个文档，编号是 DOC#0 到 DOC#3。

每个文档后面都写了抓回来的总词数：image-to-3d.ai 首页 1524 个词，meshy.ai 首页 996 个词，3daistudio.com 首页 3145 个词，面包词条 6720 个词。这里的词数把导航、页脚的字也算进去了，而且面包词条词最多，后面照样排在最后，所以词数只是先看一眼，有没有写对词，要到后面几步看。

## 第二步：看提取出来的字段

抓回来的 HTML 很杂乱，提取器会从里面找出 SEO 最关键的几个位置：title、各级标题 H1 到 H6，还有 meta description。

模拟器提取字段：title 和各级标题参与排名，meta description 不参与

在模拟器里，title、各级标题和正文会进入索引参与打分。meta description 不参与打分，只在搜索结果里当摘要展示，影响的是用户点不点。

TDK 里的 K 早就没用了，所以我说可以把 TDK 改成 TDH。H 就是网页的各级标题，大多数时候指 H1，但 H2 到 H6 也有作用。具体可以看《【哥飞SEO教程】从 TDK 到 TDH》。

## 第三步：分词，建正向索引和倒排索引

下一步是分词。真实的搜索引擎会对 Title、Body 正文等所有内容做分词处理，模拟器里也是这样做的，只是页面上只演示了 Title 是怎么被分词的。

分词之后，先建立正向索引，记录每一个文档由哪些词组成，每个词出现了几次，也就是词频。比如 image-to-3d.ai 首页，3d 这个词一共出现了 170 次，title 里 2 次，H1 里 1 次，正文里 140 次，其余 27 次在 H2 到 H6 和网址里。

再把正向索引反过来，就是倒排索引：

- • 正向索引：每一个文档对应哪些词
- • 倒排索引：每一个关键词对应哪些文档

模拟器里这一步可以点来点去。点文档，能看到它对应哪些关键词；点关键词，能看到哪些文档里有它。

## 第四步：输入关键词，看你的网页能不能被选出来

索引建好，就可以模拟搜索了。

搜索也分好几步。先把用户输入的关键词分词，再做一些处理，比如去掉停用词。image to 3d model ai 分完词，to 被去掉，剩下 image、3d、model、ai 四个词。

然后每一个词都去倒排索引表里查，看它对应哪些文档。最后把所有查出来的文档合在一起，进入候选集。

模拟器搜索召回：每个查询词命中的文档合并成候选集

三个 3D 网站的首页，四个词都有。面包词条正文里出现过 2 次 image，只命中一个词，也进了候选集。所以进了候选集，不代表能排到前面，面包词条后面就排在最后。

到这一步大家就能明白，如果我们的网页用的是前端渲染，爬虫抓不到网页文案，或者网页只放了工具功能，没写文案描述，那么在这一步，我们的网页根本进不了候选集，也就压根不可能出现在搜索结果里。

前端渲染会有什么问题，我以前专门写过一篇：《【哥飞SEO教程】如果不想要谷歌给的免费流量，你就用前端渲染吧》。

我多次强调，网页 TDH 要写好，网页单词数量至少 600 到 800 个，写到 1200 到 1600 个更好，就是为了让我们的网页在这一步能被选出来。

## 第五步：看排序，展开打分明细

选出来的候选集里，可能有几千几万个网页，但搜索结果第一页只能展示 10 个。到底展示哪 10 个，每一个排第几，这是搜索引擎最核心的商业机密，我们外人无从得知谷歌内部具体是怎么排的，用到了哪些参数。

但全世界的 SEOer 那么多，总能从谷歌的官方资料、发明专利、打官司公开的资料、不小心泄露的资料、全球网站的实际表现、真实搜索结果里收集蛛丝马迹，大概推断出搜索引擎的喜好。

我们总结出来，在谷歌想拿到靠前排名，要做好这几件事：

1. 1. 网页内容 On Page SEO 要做好；
2. 2. 网页功能体验要做好，要能满足用户需求，让用户留下来，持续使用；
3. 3. 要有外链；
4. 4. 网站要能持续更新，而不是几年不变；
5. 5. 网站小而专比大而全更好；
6. 6. 新站初期不要批量上大量页面，一个一个做精品页面更好。

模拟器为了演示搜索结果排序，不考虑别的因素，只看 On Page SEO 的关键词匹配。

模拟器排序结果：每个网页的得分由各字段贡献拼成

三个 3D 网站的首页得分很接近：image-to-3d.ai 3.5663，3daistudio.com 3.5573，meshy.ai 3.5189。面包词条只命中了 image 一个词，得分 0.1075，排在最后。

每一个网页都可以展开打分明细，看它是怎么被排到当前位置的。我展开了排第三的 meshy.ai：

meshy.ai 首页的打分明细和 On-Page 诊断

model 这个词，meshy.ai 首页只在 title 和正文里出现，H1 和 H2 里都没有。排第一的 image-to-3d.ai，model 出现在 title、H1、H2、H3 等好几个位置。

下面的诊断还提示，这四个词在 meshy.ai 正文里各出现了十几到五十几次，模拟器里一个词重复到 4 次左右以后，再多也几乎不加分了。所以在模拟器里，同一个词反复往正文里塞，加不了多少分。

换一个词搜，结果也会变。我把关键词改成 ai 3d model download，3daistudio.com 以 3.4252 分排到了第一，image-to-3d.ai 3.4184 分排第二，meshy.ai 3.3955 分排第三。用户搜的词不同，匹配到的网页、命中的关键词也不一样，排序就不一样。

模拟器里的排序和谷歌真实排序也不一样，谷歌里 meshy.ai 就排在 3daistudio.com 前面。谷歌还要看体验、外链、更新这些因素，模拟器能帮你看清楚的，只是 On Page 这一部分。

## 为什么新词出现后，全新的网站也能拿到排名

再用模拟器演示一个情况。

我们先假设，一个关键词出现之前，整个互联网上都没有能匹配这个词的网页。新词出现后，我们快速做了一个页面，上线了一个网站。

假设这个词就是 EKGR Calculator，我们做的新网页是 seo.box/keyword/。搜索引擎里已有的老网页，就用 3daistudio.com、sloyd.ai、magic3d.io 这几个 3D 网站的页面。这样加上我们的新网页，这个模拟的网络里只有 4 个网页。

建好索引，去搜 EKGR Calculator：

搜 EKGR Calculator，候选集里只有 DOC#3 一个网页

候选集里只有一个网页 DOC#3，也就是 seo.box/keyword/ 这个新页面。

只有一个页面候选，这时候再多的排序因素都没有用了，只能显示这个页面给用户看。

真实情况会更复杂一些，但原理是类似的。能匹配上用户搜索词的网页没几个，这时候排序因素里的关键词匹配，就占了更大的权重，其他什么外链、什么权威度、什么新鲜度通通都靠边了，于是新词新站就拿到了靠前排名。

但是情况会变化。如果有更多人发现了这个新词，也上了页面，有些人用新域名上线，但发了不少外链；有些人用高权重老域名的内页上线。这时候，被选出来的几个页面里，我们的新页面如果完全没有外链，就有可能权重不够，被挤到后面，老站的内页拿到了靠前排名。

当然，谷歌实际还会考虑更多因素，会有一些先发优势。如果你先上线的网页已经能满足用户需求了，后上线的页面即使权重更高，也不太会一下子就排到你前面。但如果后面谷歌发现，后上线的页面也能很好地满足用户需求，用户喜欢用，权重还更高，那么慢慢地，谷歌也许就会把后上线的网页放到前面了。

所以做新词，要快，上线之后也要接着做外链、做体验。新词为什么要快，可以看《新词新站，快就是优势，快人一步，那就步步都快》。

## 品牌名也是同一个道理

我让大家给自己的网站取一个独一无二的品牌名称，也是一样的原理。

我们的品牌名称其实就是一个新词，只有我们自己的网站出现了这个词，别人的网页没出现，那么用户搜索我们的品牌名称时，我们的网站就应该排在前面。

那如果我们把网站提交到了一些导航站，导航站的页面也会出现我们的品牌词，为什么排在前面的还是我们的网站？

这跟刚才说的先发优势有点关系。我们的网站先出现这个词，而且种种迹象表明，我们网站的名字就是这个词，谷歌就会把这个词跟我们的网站绑定，认为用户搜这个词就是想找我们的网站。

还有朋友会问，在 Cursor 这个编程软件出来之前，互联网上已经有很多关于“Cursor”的网页了，为什么后来 Cursor 能排到第一名？

这是好几方面因素加在一起的结果：

1. 1. Cursor 刚出来时，有一小帮用户扩散消息，让更多人知道了它，于是大家去搜索引擎搜索下载。那时候 Cursor 只是一个技术名称，指鼠标光标，也是 CSS 里的一个关键词，没有特别出名的产品叫 Cursor，竞争并不激烈，所以 Cursor.sh 也能拿到 Cursor 这个词的排名。也许最开始它并不是排第一，但大家搜这个词，就是要找能下载 Cursor 编程软件的网站，最后都会打开 Cursor.sh。谷歌慢慢感受到这样的用户行为，就会把 Cursor.sh 的排名提上去。
2. 2. 越来越多的用户在互联网上提到 Cursor，语义上关联到的都是 Cursor.sh。
3. 3. 越来越多的外链指向 Cursor.sh，锚文本里包含“Cursor”。
4. 4. 越来越多的媒体稿件提到 Cursor，指的也是这个编程软件。

久而久之，谷歌就知道 Cursor 是 Cursor.sh 的品牌名称，于是把 Cursor.sh 排到了第一名。后来 Cursor.com 被买回来，老域名跳转到新域名，谷歌也知道 .com 是他们的新网站，于是又把 Cursor.com 排到了第一名。

在 Cursor 之前，没有一个影响力特别大的产品叫 Cursor，于是它可以用 Cursor 做品牌名称。Notion、Claude 也是一样。所以我们取品牌名称时，不一定要造词，也可以用一个现成的单词。

## 写完网页，先放进模拟器跑一遍

最后把用法整理一下。写好一个网页后，可以这样检查：

1. 1. 在谷歌搜你想做的词，拿排在前面的 3 到 5 个网址，加上自己的网页，再掺一个不相关的网页，一起放进模拟器。
2. 2. 看自己的网页抓回来有多少个词。词数很少，先查是不是只放了工具、没写文案。
3. 3. 输入目标关键词，看自己的网页每个词都命中了没有。有的词一次都没命中，先查页面上是不是根本没写，或者文案是前端渲染出来的、爬虫抓不到。
4. 4. 词都命中了，再展开打分明细，看目标词有没有出现在 title、H1、H2 里，跟排在前面的网页差在哪个字段。
5. 5. 改完上线，再放进去跑一遍。

模拟器只看 On Page 这一部分。页面体验、外链、更新这些，还要另外去做。
