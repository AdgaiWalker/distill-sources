年化收入40万美元小产品，始于 2019 年，功能很少，但真的能解决需求

Tiiny Host ：   只是帮人发个文件，凭什么做到年化收入40万美元？

大家好，我是哥飞。

做完一份 PDF ， 想发给别人看，通常要发附件，或者传到网盘。做完一个网页，想让别人打开看看，还要找地方部署。

Tiiny Host     把这两件事做成了同一个动作：上传文件，生成一个可以分享的链接。

听起来很小，甚至会让人问：免费的办法已经很多了，为什么还有人付钱？

年，创始人 Elston Baretto 披露， Tiiny Host 的年经常性收入达到 40万美元。他从 2019 年开始做这个产品，第一年的月经常性收入长期不到 100美元；到 2021 年，才做到约 2000 美元。

最初，他做的是网页托管。用的人多了，他才发现，用户想分享的还有课件、PDF 文档，以及刚做好的小网页。

第一版只有一个上传框

十几岁就开始做网站，也接过开发订单。后来读了计算机专业，在银行Elston

工作，又去过创业公司。工作之外，他尝试过不少小项目， Tiiny Host 也是其中一个。

2019   年，他利用业余时间，花了大约一个月做出第一版。

页面很简单，不需要往下滚动。用户把网页文件打包成 ZIP ， 拖进去，就能把网站放到网上。没有复杂的设置，也没有一长串产品介绍。

早期他到创业者和开发者交流的社区介绍产品，找到了最初的约 200 位用户。

用户反馈里，还出现了他原先没想到的用途。

一位老师用 Markdown 做幻灯片，想把课件放到网上给学生看。这个原本用来上传网页的工具，也能帮他分享课件。 Elston 开始从这些反馈里了解用户的具体用途。

第一版也有明显的问题：上传之后，网站要等 15 到 20 分钟才能上线。用户不能立刻打开链接查看结果。第二版把这段等待缩短到几秒，上传后就能检查网页，再把链接发出去。

还有人打开网站，手边根本没有一个做好的网页文件。为了让他们也能试，Elston 加了可以直接上传的示例模板。这个入口后来成为用户体验产品的重要方式。

最开始， Tiiny Host 是免费的。随着用户反复提出更大的上传容量、自定义域名、密码保护等要求， Elston 才把这些需求做进付费版，并补上管理已上传网站的后台。

推广付费版时，他做了半价优惠。第一位客户用优惠价购买，第二位客户则按原价付款。

到 2021 年， Tiiny Host 托管过约 4 万个网站，有 250 多位付费用户，月经常性收入约 2000 美元。

用户绕了一步，他把那一步接过来

另一次变化来自 PDF 。

注意到，有用户会先把 PDF 转成 HTML ， 再拿到 Tiiny Host 上传。当Elston

时产品只支持网页，他们为了分享 PDF ， 只好多做一次格式转换。

他于是增加了直接上传 PDF 的功能。用户不必转换格式，也能生成链接，让别人在线查看文档。

到了 2024 年初，他披露，产品的月经常性收入约 1.5 万美元，付费用户接近1000 人。他当时估计， PDF 上传功能贡献了约四成收入。

获客也逐渐有了分工。他找人研究搜索词，整理成选题，再交给写作者，每周发布两篇文章。其中一个方向就是：怎样把 PDF 变成可以分享的链接。

读者搜索怎样分享 PDF ， 就能找到这类文章，再顺着教程使用 Tiiny Host 。

只分享一个文件，18美元的套餐太贵

当时最低的付费套餐是每月 18 美元。有些用户只需要分享一个文件，用不上套餐里那么多东西。 Elston 在免费版和 18 美元的套餐之间，增加了更便宜的Lite 档。

他披露，这次调整让转化率翻倍；还有用户先买 Lite ， 用过之后再升级到 18 美元的套餐。只需要一个链接的人，先有了更便宜的选择。

他也把七天试用改成了可以长期使用的免费版。免费用户分享的页面带有产品标识，收件人打开文件时也能看到 Tiiny Host ， 分享本身因此成了一种展示机会。

允许用户上传文件，也带来了内容审核的问题。 Tiiny Host 曾因违规内容险些被云服务商暂停服务，后来不得不增加审核和拦截措施。让上传变得方便的同时，还要处理文件能不能留在服务器上。

到 2025 年， Tiiny Host 的年经常性收入达到 40 万美元。如今，首页已经把文档、图片和代码放进同一个上传入口，早期分享课件和 PDF 的用途都能直接找到对应功能。

搜索“怎么分享”，页面就给上传入口

Tiiny Host   首页的介绍很直接：用简单的方式，把你的作品放到网上并分享出去。

下面就是上传框。用户可以选文档、图片、代码，也可以直接粘贴 HTML ； 输入链接名称，文件就有了一个容易辨认的地址。没有文件的人仍然可以用示例体验。

Tiiny Host   首页：文档、图片和代码共用上传入口上传框上方的链接名，填的是地址的前半部分，后面已经带着 .tiiny.site 后缀。临时分享文件，不需要先买域名，也不用配置域名解析。用户选好文件、取好名字，就能继续上传。等到要用自己的品牌对外展示，再考虑支持自定义域名的付费套餐。

早期只能拖入网页压缩包，现在可以按文件类型选择入口。想分享文档的人不用先了解网页托管，选中文档、上传即可开始。

搜索用户也未必从首页进入。

我查到的美国关键词数据里， how to create a link to a pdf ， 也就是 “ 怎样给PDF 创建链接 ” ，对应 PDF 分享页，排名第 2 ； html to website ， 也就是 “ 把

HTML   变成网站 ” ，对应 HTML 上传页，排名第 3 。

两种搜索进入不同页面。前者开头就写 “ 创建 PDF 链接 ” ，后者介绍怎样让HTML 文件上线，页面里各有相应的操作入口。

PDF   分享页：标题下方就能选择文件并创建链接

PDF页面把上传入口放在第一屏，下面才解释分享之后还能做什么：浏览器直接查看；更换文件时保留原来的链接；需要时给链接加密码，或者使用自己的域名。

资料发出去之后，如果内容有改动，可以更新文件而不换链接。收件人仍然从原来的地址打开，用户不必再发一遍新链接。

如果文件不能公开，就需要密码保护；如果要用自己的品牌对外展示，就会在意域名。上传之后的这些要求，也成为套餐中的付费功能。

教用户做出来，再教他发出去

并不是每个搜索用户都已经有文件。

关键词里还有 “ 自己做Wordle” ，也就是制作一个猜单词小游戏。customwordle 在这份数据中排第 15 ， make your own wordle online 排第 14 ，进入的都是同一篇制作教程。

关键词记录：两个自制 Wordle 搜索词进入同一教程

这篇教程从 “ 给朋友或者学生做一个自己的小游戏 ” 开始，教用户让 Claude 生成代码，再调整主题、词长和规则，测试后下载 HTML 文件。

到这里，用户已经做出了一个能在自己电脑上打开的游戏。但如果想让朋友点击链接就能玩，还差上线这一步。

教程接着带用户去 Tiiny Host ： 上传 HTML ， 给链接起名字，登录或注册后发布。一个搜索制作游戏的人，就这样遇到了文件托管的实际需求。

用户已有文档，页面直接给上传入口就够了；做小游戏的人还没有文件，需PDF

要先讲制作步骤。虽然最后都用到了托管，前面的内容不能照搬。

以前我写过 以这个 Favicon 图标生成工具为例，哥飞告诉你，好用的工具要怎么做。那个工具生成图标后，会告诉用户怎样把图标放进项目。 Tiiny Host的教程则在游戏做好后，继续教用户上传文件、生成链接，把游戏发给别人玩。

如果想采用这种教程获客方式，可以先检查教程的最后一步：读者做出了什么文件，要发给谁，为什么需要一个在线链接？这篇小游戏教程对应朋友和学生，文件上传后，对方打开链接就能玩。换成其他教程，也要找到同样具体的使用场景。

免费就能发文件，付费买哪些便利？

从这些页面进入网站，不用付费也能上传一个文件或网站，生成分享链接。免费版限制文件大小、访问量和带宽，分享页上还会显示 Tiiny Host 的标识。

当前 Tiny 档按年付费，折合每月 5 美元，仍然只支持一个在用项目，但允许更大的文件，并去掉产品标识。 Solo 档按年付费折合每月 13 美元，支持五个项目，以及自定义域名、密码保护等功能。

按这个年付价格计算， Tiny 一年是 60 美元， Solo 一年是 156 美元。

偶尔分享一个小文件的人，可以留在免费版；想把资料作为正式展示的人，可能更在意去掉产品标识、使用自己的域名；同时维护多个文件的人，则需要更多项目名额和管理功能。

分享页本身也放了套餐说明。用户先看懂怎么上传，再往下就能比较免费限PDF

制和付费功能，不必返回首页找价格。
