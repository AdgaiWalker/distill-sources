一个在线白板工具还有 428 万访问，真正厉害的是用户会主动回来

大家好，我是哥飞。

很多在线工具，用户用完一次就走了。

比如临时压缩一张图、转一次格式、生成一段文本。需求是真的，但下一次用户未必还记得你。

所以看工具站，我现在会特别关注一个问题：用户会不会主动回来？

今天看 Excalidraw 。

它是一个在线白板工具，打开网页就能画草图、流程图、架构图、需求图。界面很轻，手绘风格很明显，不需要先注册账号，也不需要先建项目。

Excalidraw   在线白板界面

这种工具的好处是门槛低。

你开会时想解释一个流程，写方案时想画一个结构，和同事讨论需求时想把想法画出来，打开就能用。

它解决的是一个很普通的动作：把脑子里的东西画出来，让别人看懂。

这个动作一旦和工作有关，就有重复发生的可能。

今天画一个产品流程，明天画一个技术方案，下周开会再画一个解释图。用户用顺手之后，下次未必重新搜索，可能直接输入域名、从浏览器历史记录打开、从收藏夹打开，或者从团队文档里点进去。

这就是 Excalidraw 比普通一次性工具更值得看的地方。

它还有一层基础，藏在开发者社区里。

开源对这种工具很关键。

开发者会在 GitHub 、文档、 npm 包里遇到它。很多产品团队、技术团队也会把它当成一种 “ 画图语言 ” ，放进自己的沟通流程里。

这样一来， Excalidraw 超过了普通网页工具的范围。

它可以是会议白板，也可以是需求草图，也可以是文档里的图，还可以是别的产品里嵌进去的一块能力。

到这里，再去看流量就更容易理解。

在 Similarweb 上看， excalidraw.com 6 月访问量是 428 万左右。

Excalidraw   访问趋势

在线白板很少有每天刷屏的热点。它也不像 AI 新闻，一有新模型就能带来讨论。一个白板工具还能有几百万访问，背后通常靠的是稳定使用场景。

要判断这种稳定性，渠道构成比单个访问量数字更有用。

Excalidraw   流量渠道

直接访问约 65.30% ，自然搜索约 23.81% 。

这两个数字放在一起看，比单独看自然搜索更有意思。

直接访问占比高，说明很多用户已经把它当成固定入口。自然搜索如果主要来自Excalidraw相关词，也不难理解：有些人不会记域名，想用的时候就在Google 里搜一下 Excalidraw ， 再点回来。

这和一次性工具不一样。

一次性工具通常靠搜索进来，解决完就走。下次用户还有同样问题，可能重新搜，也可能换一个站。

Excalidraw   这种工具，一旦进入用户习惯，就会被反复打开。

这就是直接访问和品牌搜索一起出现的价值。

它说明这个站在一部分用户心里已经有位置了。

渠道只能告诉我们用户从哪里来，还不能解释它为什么会进入工作场景。出站目的地能补一层线索。

Excalidraw   出站目的地

出站里有 Google 、 YouTube 、 GitHub 等。

说明用户会在搜索和工具之间来回切换。 YouTube 很容易理解，画图Google

工具经常会有教程、演示、模板和使用方法。 GitHub 则和开源生态连在一起。

把前面的信息连起来， Excalidraw 的脉络就比较清楚了：

用户从搜索里找到它；

用过之后直接回来；

开发者从 GitHub 和文档里遇到它；

团队把它放进会议、文档、方案和协作流程里。

这比单纯做一个网页工具扎实很多。

Excalidraw   还有一个值得看的地方：它把免费白板延伸到了协作和付费能力。

Excalidraw+ 里能看到云端保存、团队协作、演示、评论、 PDF/PPTX 导出、更多  AI   请求等功能。免费工具负责降低门槛，协作和团队功能负责把使用场景变重。

Excalidraw+   协作能力

做工具站的人可以多看这条路径。

先用一个足够简单的工具切进日常动作。

用户不需要学习，不需要想很久，打开就能解决一个问题。

等用户愿意反复打开，再把能力往协作、保存、团队、导出、嵌入这些方向延伸。

因为个人临时画一张图，付费意愿可能不强。

但团队要保存资料、管理作品、协作讨论、导出文件、做演示，价值就变清楚了。

所以看 Excalidraw ， 别只看它是一个画图网站。

更应该看它进入了哪些固定动作：

第一，表达想法。

很多人写不清楚的时候，会画一下。产品经理、程序员、设计师、运营，都可能有这个需求。

第二，沟通协作。

一个图比一大段文字更容易让团队对齐。会议、需求评审、技术讨论，都可能反复用到。

第三，开源生态。

开发者会在 GitHub 、 npm 、文档、教程里遇到它。这个入口不一定每天爆发，但会长期存在。

以后看工具站，我会多问三个问题。

先问：它会不会变成一次性需求？

如果用户用完就走，下次完全靠重新搜索，这个站的流量会比较脆。

再问：用户有没有理由主动回来？

能被收藏、被团队反复打开、被放进工作流程里的工具，直接访问通常会更强。

最后问：它有没有生态里的二次传播？

开源、插件、模板、教程、文档、嵌入能力，这些东西会让一个工具不只靠官网自己获客。

Excalidraw   给我的启发很简单：工具越简单，越要看它有没有重复使用场景。

小工具也可以做出长期入口。

如果它切进了一个高频动作，用户会主动回来，团队会一起用，开发者会传播，它就有机会从一个网页工具，变成一个长期入口。

做网站也是这样。

不要只问 “ 这个需求有没有搜索量 ” 。

还要问：用户下一次需要的时候，会不会想到我？会不会直接打开我？会不会在别人的教程、项目、文档或团队流程里再次遇到我？

这几个问题答得越清楚，这个工具站就越值得拆。
