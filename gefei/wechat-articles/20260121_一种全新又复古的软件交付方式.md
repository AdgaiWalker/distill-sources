一种全新又复古的软件交付方式

大家好，我是哥飞。

最近观察到一种趋势，

没有任何开发经验的人，

基于自己对行业的理解，

基于自己的需求和同行的需求，

用 AI 写代码，做出来了一个产品，

最终交付给用户的是纯静态的 HTML 单文件，

用户收到文件后用浏览器打开就可以运行起来。

然后开发者卖的是 API Key，

每一个 Key 都可以限制积分，

用完积分了，用户再买新的 Key 替换上去，

而所有的信息都存储在用户本地，也不担心流失。

这样的软件，怎么卖呢？

直接小红书发软件使用视频，

就能够吸引到可能感兴趣的用户。

当然，还有些软件，不需要 API 即可运行的，

就不是卖 API Key 了，而是直接卖 HTML 文件，
