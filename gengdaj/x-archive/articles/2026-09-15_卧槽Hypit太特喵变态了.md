制作难度嘛，很简单，四个步骤轻松搞定✋：
1. 找到爆款视频
2.把链接地址发给Codex，安装Hypit Skill，让Codex“/hypit，帮我复刻这个爆款视频”
3.零花费生成占位素材，如果有误差，让Codex继续调整字幕，保证准确性
4.调用真实API生成所有素材和最终视频，不满意的地方可以继续用Codex调整

🔑因为是完全开源的，所以所有的 API 都可以自己任意接入。
我在不同环节使用的一些 API 供大家参考：
1、理解需求、编排工程：Codex
2、分析参考视频：Gemini 3.1 Pro
3、生成人物及主要图片：GPT Image 2
4、生成部分界面与卡片：Nano Banana Pro
5、生成部分补充图片：Nano Banana 2
6、补齐界面与网页图片：Seedream 图生图
7、设计统一声音参考：MiMo V2.5 VoiceDesign
8、生成人物讲话视频：Seedance 2 Mini
9、生成产品及操作短片：Seedance 2 Mini
10、识别口播、对齐字幕：WhisperX
11、绘制字幕、纸条和排版：本地代码组件
12、合成、导出视频：HyperFrames + FFmpeg
