## 正文

Claude Code其实可以直接调用Codex的Computer Use，就可以不占用屏幕，能同时干更多事情，物尽其用！

Codex里面的Computer Use，能读界面、点按钮，原本只有 Codex 能用。但是LCU 把这套程序单独封装成标准的 MCP 工具，Claude Code 就能调用。

而且它不需要登录 Codex，只要本机装着Codex即可。然后Computer Use本身不消耗Codex额度，因为是一个程序——读界面结构、截图、点击和输入，然后Claude进行OCR和推理会消耗自身Token额度。
